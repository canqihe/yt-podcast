深度洞察

01

计算的64年来首次彻底重塑

00:01:13 - 00:08:21
核心观点

自IBM System/360以来持续64年的计算模型正在被根本性重写——软件从「预录」转向「实时生成」，计算机从「按需响应」转向「持续运行」。

深度阐述
从预录到生成

过去64年，计算模型基本没有改变。从PC到互联网、移动到云——虽然形态在变，但底层范式一致：你写好程序（预录），计算机按指令执行。分时计算机变成云计算，本质上都是「你问，我答」。但现在一切都变成了「生成」的——生成式AI在实时生成图像、文本、推理过程，且上下文相关。计算机不再只响应明确指令，而是能理解你的意图。

从按需到持续

在智能体系统中，计算机不再按需启动，而是持续运行。这意味着从软件开发方法论、工具链、组织方式，到系统架构、网络、存储、云服务，再到应用形态——每一层都被重新定义。

GPT的启示

黄仁勋回忆15年前看到深度学习早期工作时的推理过程：从第一性原理推导，得出的结论是一切都变了。他特别指出，当GPT出现时，很多人看到的是图像生成，而他看到的是「生成思想」的能力——生成你内部消费的token叫「思考」，生成你外部消费的token叫「工具使用」。从这个洞察出发，走到今天的智能体系统，几乎是必然的。

02

协同设计与100万倍算力飞跃

00:08:38 - 00:13:33
核心观点

NVIDIA通过跨芯片、编译器、网络、系统的极端协同设计，在10年内实现了100万倍的算力提升，而纯靠摩尔定律只能做到100倍。

深度阐述
RISC的遗产

黄仁勋从斯坦福学术传统讲起——John Hennessy的RISC架构之所以伟大，在于它让编译器和微处理器架构和谐地协同设计。一个更简单的、与编译器协同设计的机器，比两个各自优化的系统性能更好。NVIDIA把这个理念推向了极致——同时优化CPU、GPU、网络交换机、存储等所有层面。

100万倍 vs 100倍

摩尔定律黄金时代10年能提升100倍（每5年10倍）。但Dennard缩放终结后，纯靠微处理器扩展10年可能只有10倍。而NVIDIA通过协同设计实现了100万倍。黄仁勋的比喻：如果你能以光速旅行，你选择住哪里就不重要了；如果你能从纽约到加州只需10分钟，社会的方方面面都会改变。同理，计算速度提升100万倍，让AI研究者可以说——「把整个互联网的数据都拿来」。

"We accelerated computing by so far that it created all this infinite abundance opportunity for everybody to think about the future." — 我们把计算加速到如此程度，为所有人创造了思考未来的无限丰富机会。

深度阐述
教科书的时代局限

黄仁勳回忆在斯坦福求学时，Hennessy教授还在手写教科书——每周写一章，几年后才汇集成第一版。传统教科书制作周期太长，无法跟上AI时代实时产生的知识。

AI作为学习伙伴

他现在离不开AI做研究：让AI读论文 → 让AI读相关论文变成超级研究员 → 先总结后深入对话。他强调在总结文档的过程中，AI本身学到了大量东西——这不是简单摘要工具，而是能持续对话的知识伙伴。

为什么NVIDIA要做开源模型

00:15:38 - 00:25:28
核心观点

NVIDIA投入开源模型并非与闭源前沿竞争，而是为了扩展AI到语言资源不足的社会、科学前沿领域，以及从根本上保障AI安全。

深度阐述
首先：NVIDIA是闭源模型的重度用户

NVIDIA是Anthropic和OpenAI的重度用户。100%的NVIDIA工程师都已配备智能体支持。黄仁勋强烈推荐所有人使用Claude Code和ChatGPT这样的前沿闭源产品——从GitHub下载的开源项目不可能达到同等效果。

理由一：语言民主化

全球有数百种语言，但只有少数几种被商业公司优先对待。瑞典语、印度230多种方言中的大部分——如果没有人特别关心，这些语言的AI能力永远不会好。NVIDIA的Nemotron（接近前沿水平的开源大语言模型）让任何人都可以微调成自己的语言。

理由二：激活科学前沿

化学、蛋白质、基因、物理系统、机器人——每种信息的结构不同、维度不同、训练方式也不同。科学家们没有规模和技术构建基础模型。NVIDIA在多个领域投入：Nemotron（语言）、BioNeMo（生物学）、Alpamayo（自动驾驶，语言模型+世界模型融合）、Groot（人形机器人）、气候科学（中尺度多物理场）。特别值得注意的是Alpamayo：将语言模型与世界模型融合，使自动驾驶模型能用人类先验知识推理，只需数百万英里而非数十亿英里就能成为最有效的系统之一。

理由三：AI安全需要透明

这是最根本的理由。对抗超级智能体网络安全威胁的正确方式，不是军备竞赛（你出模型7.0，我出8.0），而是部署数百万、数十亿的廉价AI（如Nemotron Nano）形成系统性包围——像一个巨大的防护穹顶。

"If you care to have AI be safe and secure, it has to be open. You can't defend against a black box." — 如果你希望AI安全可靠，它就必须是开放的。你无法防御一个黑箱。
05

MFU是一个误导性指标

00:26:30 - 00:32:46
核心观点

模型FLOPS利用率（MFU）是错误的方向。真正应该衡量的是token每瓦特和真实评估（evals），低MFU反而可能是好事。

深度阐述
为什么想要低MFU？

在大型数据中心中，FLOPS、内存带宽、内存容量、网络容量——在任何给定时刻总有某个东西是瓶颈。你要超额配置一切来避免Amdahl定律。超额配置意味着大部分时间很多FLOPS闲置——MFU很低。但在关键峰值时刻，你有足够的余量。

正确的指标

黄仁勋用汽车做比喻：过去问「多少马力」，现在谁还这样做？对于大语言模型推理（特别是解码），最重要的是token每瓦特。Grace Blackwell NVLink72在解码时通过聚合带宽实现极高的token每瓦特，而MFU极低——因为解码和预填充是解耦的。

多领域平衡的艺术

他描述了核心矛盾：过度优化某个特定问题，那个市场可能不够大支撑研发；什么都好就变成了通用的、什么都不好。在多领域专精和不过度特化之间找平衡——「这是一种艺术。这是我的工作。」他每天回答：不应该做什么？加倍投入什么？10倍投入什么？

"I would like to be at low MFU all the time... because I want to be so smart I'm overprovisioned." — 我一直想要低MFU……因为我想要足够聪明以至于系统超额配置。

芯片四代演进：从预训练到智能体群

00:33:14 - 00:38:11
核心观点

NVIDIA每一代芯片都瞄准下一个计算范式：Hopper（预训练）→ Grace Blackwell（推理/解码）→ Vera Rubin（智能体）→ Feynman（智能体群）。

深度阐述
Hopper：为预训练而生

当世界最大超级计算机约3.5亿美元时，NVIDIA决定构建价值数十亿美元的系统——为精确零个客户。因为他们预判预训练将是如此巨大的问题领域。这个判断极为正确。

Grace Blackwell NVLink72：为推理设计

AI的目标不是训练，而是推理。解码阶段的token生成需要极高内存带宽，远超单芯片能力。解决方案：将72个GPU联合，发明新的交换和互连系统，创造世界首台机架级计算机。结果：两年内提升50倍，而摩尔定律只能做到2倍。

Vera Rubin：为智能体设计

目标不仅是思考，而是做事。智能体的计算模式需要长期记忆（直接连接到GPU网络的存储）和大量工具（专门设计了Vera CPU——为单线程代码优化，极低延迟）。

Feynman：为智能体群设计

未来是智能体系统——智能体带子智能体，子智能体又带子智能体，形成智能体群。什么样的计算机架构能应对这种模式？这就是Feynman要回答的问题。

如何在不确定性中做战略决策

01:04:48 - 01:08:20
核心观点

通过观察→第一性原理推理→构建未来心智模型→逆向推演来做决策；追求的是减少机会成本、增加可选项。

深度阐述
五步决策法

1. 观察：AlexNet——两个工程师加一个Hinton，一举超越了几十年积累的计算机视觉能力。这是大事吗？ 2. 第一性原理推理：能走多远？还能解决什么？处理神经网络和处理浮点数有什么不同？ 3. 构建心智模型：模型会多大？计算机长什么样？ 4. 逆向推演：公司在未来中的位置是什么？然后倒推。 5. 概率化思考：「这些是可能发生的事，这些是肯定会发生的事，这些是可能发生的事。」

机会成本是真正的成本

追求一项策略的能量、时间和金钱是从别的地方拿来的。目标是让自己足够聪明，以减少机会成本、增加可选项（optionality）——「你试图让旅程本身为自己买单。」

🎯

指标决定行为

MFU是容易优化但错误方向的指标。真正重要的是token每瓦特和真实评估。选错指标就像用马力来评价现代汽车。

🔓

开源即安全

AI安全不能靠黑箱——「你无法防御你看不见的东西」。透明开放系统让全球研究者都能审视、改进、部署防御。Nemotron Nano被用于部署万亿级网络安全传感器。

🔮

芯片设计的预测性

每一代芯片瞄准下一个计算范式而非当前——Hopper预判了预训练、Grace Blackwell预判了推理爆炸、Vera Rubin预判了智能体。设计面向「精确零个客户」的数十亿美元系统需要勇气和远见。

💪

拥抱煎熬

90%的工作是艰难的——这不是失败，这是在锻炼韧性。「不要只追求快乐，也要追求一些痛苦。」当世界需要你坚强时，你不能没有那块肌肉。

计算的未来，由设计者定义

从IBM System/360到NVIDIA Feynman，计算的每一次范式跃迁都源于有人愿意为「精确零个客户」构建数十亿美元的系统。黄仁勋用15年的第一性原理推理和100万倍的协同设计证明——未来不是预测出来的，是构建出来的。
