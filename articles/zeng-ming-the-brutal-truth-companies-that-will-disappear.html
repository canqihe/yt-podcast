核心要点

01

三阶段坐标

一切通用技术都要走完「基础设施 → 应用爆发 → 原生应用」三段。token 成为全社会度量衡，标志 2026 年第一阶段基本完成；智能体阶段刚刚开场，国民级应用或许还要 8–10 年——别把窗口期算错。

02

基础设施窗口已关闭

模型是「炼油厂」、大模型公司本质是「AI 云公司」。智能飞轮一旦转起来，后来者再无积累可能；窗口已经关闭，终局是寡头垄断 + 政府强监管。

03

做复杂的活

当智能够用，做应用就不再是搭脚手架。越简单的任务越容易被模型吞掉；只有干复杂任务、建立自己的智能闭环与智能飞轮，才可能跑到第三阶段。

04

新平台做「能力匹配」

旧平台是信息匹配，新平台是能力与需求的匹配。浏览器级机会（统一 Agent 标准）可能就在未来两年；但 Yahoo 还没有影子，Agentic OS 大概率属于第三阶段。

05

组织先于战略

决策频率与质量被 AI 抬高后，科层组织生成不出新战略。「公司」会像手工作坊一样被淘汰；未来以「任务」为基本单元，像球队与合伙人企业——战略是长出来的，不是规划出来的。

06

没有巨头是安全的

移动互联网只是「1.5 的创新」，AI 是颠覆工业革命本身的生产力革命。IBM 做到过一次、微软勉强算一次，此后几乎无人穿越——但公司有生老病死，新公司才有机会。

新技术产业化的三阶段理论

曾鸣系统研究从移动互联网回溯到 PC 互联网、从云计算追溯到三次工业革命，得出新技术产业化的普遍规律：第一阶段，技术逐渐被社会接受、成为基础设施；第二阶段，基于基础设施产生海量新应用，百花齐放；第三阶段，海量应用出现后，人们发现需要更底层的方法去运行新世界，进入原生应用阶段——移动互联网时代的抖音、字节就是例证。原生应用不诞生于第二阶段，因为应用大爆发恰恰给了技术下一阶段发展的方向。字节路径是典型样本：先做内涵段子、今日头条一堆小产品试错，推荐算法这种「既是技术模式又是商业模式」的东西先成熟；带宽、算力让短视频成熟后，推荐算法 × 短视频形式才碰撞出抖音。他特意安慰第二阶段的创业者：第二阶段本身非常精彩、极有价值，可能有 8 到 10 年黄金期属于它，「你没办法跨越到第三阶段，跨不过去就没有第二阶段的积累」。

2026：第一阶段收官、第二阶段开场

把三阶段理论套到 AI 上，给出明确坐标——2026 年应是第一阶段基本完成的标志性年份。核心标志是 token 成为社会共识：黄仁勋在 GTC 说英伟达未来是「token factory」，奥特曼随即表示 OpenAI 的核心就是卖 token。当一个技术有了标准度量衡，就能被规模化、标准化使用——「今天大家都知道我调多少 token 能干多少活、产生多少费用」，这正是基础设施成熟的表现：服务越来越好、智能越来越强、成本越来越低，且形成匹配的商业模式。与此同时，2026 也是第二阶段的开场：春节前后 OpenClaw（"龙虾"）现象让所有人看到能独立完成任务的智能体的无限潜力。「所以我认为 AI 进入的第二个阶段就是智能体阶段——智能体就是 AI 时代的新应用。」

我们在等「浏览器」，而 Yahoo 还没有影子

两年前他曾演讲「让我们拥抱 Yahoo 吧」，判断 Yahoo 快来了；但今年初看到 OpenClaw 后判断反而前移了——「我们怎么退回到了浏览器阶段？我们还在等一个浏览器出来。」智能体的本质是「分享能力」，OpenClaw 提供了「能力可以被这样封装、调用」的框架；92/93 年的建站运动 = 今天的建 Agent 运动，分享信息 = 分享能力，信息时代 → 能力时代。浏览器完成两大功能：通过 HTML 树立建站统一标准、把浏览网站门槛降到 0；Yahoo 则是熵增时代的熵减——结构化信息。今天的状态是熵增过程中：各种技能能力在爆发，「随便问身边任何人，都讲不出两三个他天天在用的智能体」；完全没有看到 Yahoo 的雏形——「连浏览器现在都没出现」。所以他断言下一个最大的机会，是类似浏览器的机会：统一 Agent 的标准，让用户用极简单的方法调用 Agent，触发海量 Agent 爆发。「这可能就是未来两年最让人兴奋的一件事情。」

模型的真相：炼油厂、AI 云公司

给模型下了几层递进的类比——炼油厂（数据是石油，模型是炼油厂）、AOL（互联网基础接入服务商）、说得直白点，OpenAI、Anthropic、Kimi、DeepSeek 这些公司就是「未来的 AI 云公司」。这解释了为什么大模型公司与云厂商博弈如此复杂：云厂商觉得付出太多、得到太少，模型公司则认为将来要自建云、甚至自研芯片（如 OpenAI），两个生态会发生碰撞与重新整合。模型公司有没有机会从基础服务商变成成功的应用公司？开放问题，但他主观判断「概率不会太高」，因为没有历史先例——石油公司做不了汽车，炼油厂和化工厂是两类企业，化工（应用）比纯粹炼油要有价值得多。Codex、Claude Code 做得好，恰恰说明 coding 已成为基础智能的一部分、是模型能力的延伸。

万亿估值的「幻觉」与 Yahoo 先例

针对「Anthropic 成立不到 10 年估值万亿」的描述，曾鸣直言「这个描述本身就是一个幻觉和误解」：Yahoo 1995 年成立，2000 年市值 1200 亿美元；考虑通胀与纳指涨幅，按年化 8% 计，2000 年的 1000 亿美元约等于今天 1 万亿美元，当年 Yahoo 五年冲上千亿市值的震撼不比今天的 Anthropic 弱。AOL 2000 年高点估值 2200 亿美元（当时市值最高的公司）；谷歌 1998 年成立、2005 年千亿；黑莓也曾是最快破千亿估值的公司。结论是 OpenAI、Anthropic 的成绩确实了不起，但「这样的先例在历史上、在类似的阶段都发生过」，它们「很可能往后活得不错，但大概率不是原生应用阶段的大玩家、大赢家」。面对陆奇「OpenAI 一定会比 Google 大，只是 5 倍还是 10 倍」的论断，他的回答是：「我相信未来一定有一个 10 万亿美元的公司，但未必是现在领跑的这两家。」

模型的终局：寡头垄断 + 政府强监管

模型公司的终态非常清晰——公共基础设施行业只有一种商业模式成立：寡头垄断 + 政府强监管。社会依赖它所以政府必强监管；供给如此重要所以不能只有一家供应商；投入巨大所以不会无序竞争。「你现在水电费能随便涨价吗？当然不能。」这就是基础设施的定义。寡头化的过程中已经有人掉队了：Anthropic 先领跑、OpenAI 跟上、Google 阶段性被甩开，xAI 和 Meta 直接退出竞赛。

智能复利与黑洞效应

用「智能复利」解释掉队者——Anthropic 从去年下半年到今年上半年开始用大模型训练大模型，把 AI 工具用到了自己的主业上，模型训练能力大幅提升；再加上组织优势与战略聚焦，组织优势叠加新技术运营方式就产生巨大领先优势，开始把较弱玩家甩出去，形成黑洞效应——「因为模型会继续往自我改进的路上走，差距越拉越大」。这也是美国云厂商开始慌张的原因。中国模型公司会持续追赶发展，但内部竞争类似美国，是「淘汰赛」——「今年年底谁跑不到 3T 的模型，估计就出局了。像世界杯，现在是 8 进 4，接下来 4 进 2。」K3 刚做到 2.8T，智谱有点领跑，Kimi 在 3T 上先交卷且成绩基本满意，接下来看 MiniMax 与千问。寡头竞争的特征是「有一定差异化、又足够同质化」，所以模型公司是「很好的成熟生意」，但「不会是当红炸子鸡；过个三五年若没进入下一阶段竞争，就成了大家调用的服务」。

深度阐述
去年是过家家，今年才真正开始干活

去年夏天硅谷经历了第一波 Agent 火爆，任何 demo day 都有十几个项目，但大多是广告素材生成、投放之类极简单任务，「我当时就觉得不太可能有长期价值」。去年大家像「小孩过家家」，考核标准只有 ARR，新技术的 ARR 当然有人付费，硅谷像创业天堂，人人玩得很 high。今年模型能力大突破，那批「过家家的小孩子就被淹没了」。用「脚手架」与「智能闭环」划出分水岭：当智能能力不够时，做应用很大程度上是在搭脚手架，等着模型把你淹没了；而今天做应用的思路要完全反过来——假定智能完全够用，然后看它到底能干啥活。今天的核心是干活，而且是干一个复杂的活。越简单的活越容易被复杂的活吞掉，因为它没有成长空间。只有做复杂任务，才有可能建立自己的智能闭环、积累有价值的技术积累。至于 Manus：当初市场感觉非常敏锐——抓住了 coding 能力溢出那扇难得的机会窗，通用智能体触达 prosumer 的生产力需求，那个切入点在当时是对的；但今天一个 Agent 要站立住，至少要找个 10 倍以上的切入点。垂直还是通用，是接下来比创造力、比天分的地方——教育、健康是典型大垂类；to B 端预测年底会出现一堆「组织大脑 / 组织操作系统 / CEO 的 Agent 团队」；to C 端则重新出现情感陪伴与问题解决型产品。

数据飞轮升级为智能飞轮

流行的悲观论调是这一波应用很难形成互联网时代的数据飞轮。他的回答是：数据飞轮升级成了智能飞轮。完整链条——调用基础智能让 Agent 以更高智能完成特定任务 → 任务执行中必然产生数据飞轮 → 数据飞轮的前提是真实世界的反馈，而真实反馈的前提是 Agent 独立干活、离开人的参与 → 过程中必然伴随算法创新（上下文管理、记忆、新交互方式）→ 形成「智能赋利」，Agent 在场景中越来越聪明 → 智能复利渗透延伸到更多场景、解决更复杂任务。谁找到（或运气好撞上）最有规模化、最能泛化的场景，谁就最可能形成黑洞效应、跑出来进入第三阶段竞争。这也是为什么他断言：第二阶段最好的东西一定是「口碑」爆发的（像龙虾、像 Yahoo），因为体验上有大突破，不需要投放。网络效应在 AI 时代依然存在（是基础设施级标配），但升级版是黑洞效应——应用场景越多、连接越复杂，越可能拓宽智能。DNA 双螺旋——数据智能 + 网络协同——黑洞效应是两者的同时升级。

新平台不来自旧平台

被问「新时代还会出现平台吗」，斩钉截铁：入口就是平台，肯定会。逻辑是：上一代平台大多因为信息效率不够高而存在；今天可以用「判断力」替代信息不对称，但判断力同样稀缺——而且判断 Agent 的能力比判断网站难得多。所以用户大概率会把判断力让渡给一个值得信任的独立第三方——典型的双边市场：海量 Agent 开发商 × 海量用户之间的匹配。关键差异在于：旧平台做的是简单的信息匹配，新平台要做的是能力与需求的匹配——复杂度高很多，两边都是新物种。「虽然是匹配，但匹配的东西不一样，所以大概率会诞生新的公司——你不是 Agent 的原生玩家，怎么判断得了 Agent、怎么给它提供最好的通用开发平台？」

Agentic OS 与原生的张力

从德鲁克三革命到「创造力时代」

曾鸣借用德鲁克的经典框架：第一阶段生产力革命（流水线取代手工作坊）；第二阶段管理革命（约百年前，泰勒的科学管理催生了商学院这个新物种，为现代化管理匹配管理人员）；第三阶段知识革命（70 年代起软件处理人类知识、沉淀最优实践为标准执行方法）。他由此提出：从人的角度看，AI 时代可定义为创造力时代——所有能被结构化处理的知识型工作都会被 AI 接管，人一方面被逼着开发新潜能，另一方面「终于被解放出来」去开发潜能。「这个空间非常大……创造力可能不是简单的会写歌、会画画，而是更多地原创性地定义复杂问题的能力。」正如电发明、流水线出现后才产生「产业工人」「技术工人」「白领」这些 19 世纪人无法想象的角色，未来所有人努力的方向就是开发自己的创造力——而且是一种「原创造力」、无中生有的能力：「有的东西 AI 都有（机器都当作 data 获取了），人需要做无中生有。」有些创造从机器角度「很无聊」（如各种情感陪伴、人际间「有的没的」的需求），但可能对人类成长与幸福感大有帮助。落到社会层面：商学院会消失吗？「商学院已经不行了，都在衰弱」；围绕公司建立的办公室等可见形态都会巨变——虚拟世界比例会越来越高，「metaverse 的方向没错，可能只是时间早了五年」。教育体制一定会变：现在的教育本质是「知识灌输 + 智商激励」，「从小到大多少兴趣被压抑了，我们为了不输在起跑线上，被按在原来世界的固定模式里」；年轻人已经知道未来完全不同（「随便问个高中生，都知道用现在的方法大学毕业找不着工作」），家长也知道要用新方法教育、只是不知道用什么方法——「接下来最大的冲突是教育系统的冲突，这是整个社会需要花巨大资源探索的方向」。人与 AI 的关系是组织内的深度协同；这一轮能看到的 AGI 会渗透方方面面——人会成为「加强版的人」：挂摄像头、戴语音设备、满身可穿戴、再上外骨骼，「这个完全可以想象」。硬件新物种层出不穷，但就像电器史，烤面包机这样不够大、技术不够复杂的东西养不了一家大公司，「哪些是大东西、哪些是小东西，谁用哪种方法找到面向未来的密码，都不确定」。

拥抱不确定性 + 尾声 快乐研究员

给出一个态度转变：「原来我们倾向于降低不确定性；但这个阶段其实要拥抱不确定性——不确定性就是最大的机会。见到不确定性和复杂性就恐惧，肯定没法往前走；觉得特别好玩、特别有机会创造新东西，才是年轻一代创业者的心态。我们有点杞人忧天，替他们担心得太多了。」被问自己的使命，笑答：「做一个快乐的研究员。」日常就是跟创业者聊天、看最新资讯与访谈——「这些完整的对话帮我省了很多事，等于我有大量信息输入，可以做'数据训练'，让自己不那么累。」他也提醒：今年上半年很多人都被 AI 工具弄得极度疲惫——「你根本跟不上它的处理速度」，所以要刻意建立隔绝、找到作为生物人的合理节奏，再与 AI 建立新平衡。AI 会让人类更快乐吗？他希望如此：衡量指标上文明是进步的——工业时代规模化解决了温饱这个数万年的问题，消费时代解决了消费不足（如今已供给过剩），互联网解决了信息不对称，AI 让我们能做更有趣的事。组织的一个评判标准将变成：能不能让身处其中的人更快乐。他回溯 2007—2008 年的 Google——当时硅谷神一样的存在（无数人去参观只为吃顿饭）：尊重人的差异化、释放创造力、20% 自由时间、最好的食堂——「Google 最早隐隐约约感觉到，互联网时代需要新的文化、新的组织方式，那个趋势会延续下去。」

快问快答与人之书

快问快答里也有大量信息量：最爱食物——辣椒炒肉（「我们是为了在硅基生命到来之前，留下更多碳基文明的记忆」）；最喜欢的全球地点——上海；不读 AI 技术论文；当下最关键的一个 bet——「出现一个足够好用的 to C 的 Agent」；听到「语言即世界」的反应——「可能要改成'智能体即世界'」；人生之书——《基业长青》系列、德鲁克的书，以及本科时几乎全文抄录的弗里德曼关于市场基本运行机制的小书（建立了他对市场机制的理解）；为什么学战略——高中时代（第一届文理分科）就放弃理科奥数转向历史人文，大学发现经济学数学要求超过大多数工科「太无聊」，博士选了商学院里「必须在真实世界与理论世界之间建立连接」的战略学科。

关于字节与张一鸣

有战略能力的创始人并不多；战略驱动已算优秀，「卓越严格讲得是使命驱动」——有人先有愿景再发展出使命，也有人天生使命驱动；团队里有战略强与动手强的互补（如王兴与王慧文）极难得。字节属于哪种驱动？曾鸣坦承与张一鸣个人交流不多、无法判断他的使命段，但认为「张一鸣是了不起的天才，有完整的管理哲学，至少是愿景驱动」——他最早提出「公司即产品」非常领先，字节也是最早跟上 Netflix 文化的中国公司，最终做成了「效率工厂」（战略清楚后追求执行效率）；也正因如此，「字节的 AI 战略要张一鸣重新下场再重新定义」。而任何公司的组织宿命是：时代一定会变化，让你原来那套不再适用——你要么彻底转型，要么被时代淘汰。「对每个人都很公平。」

精华收获

🗺️

三阶段坐标

新技术产业化必经「基础设施 → 应用爆发 → 原生应用」三阶段。2026 只是第一阶段（token 定标）完成、第二阶段（智能体）开场——国民级应用可能还要 8 到 10 年，别把窗口期算错。

⚖️

两个规律

第一阶段企业很难活到第二阶段、第二阶段很难活到第三阶段（炼油厂 ≠ 化工厂）；模型终局是「寡头垄断 + 政府强监管」。判断一家公司时，先问它属于哪个发展阶段。

🤖

做复杂任务

智能时代的应用公司要想存活，必须默认智能够用、去干「复杂的活」，建立自己的智能闭环与数据（智能）飞轮——简单任务只是等着被模型吞掉的脚手架。

🧠

组织先于战略

决策频率与质量要求被 AI 抬升后，旧科层组织生成不出新战略。未来组织以「任务」为基本单元、像球队与合伙人企业，核心是让洞察涌现的「战略生成系统」。

⭐

优秀 ≠ 卓越

优秀是共识赛道里的持续正反馈，卓越是被事后认定的反共识穿越者；自我越小、越把成功归于时代与他人，才可能走远——「十年后你对自己的满意」是试金石。

🌊

没有巨头安全

AI 是颠覆工业革命的生产力革命（不是移动互联网式的「1.5 创新」），旧物种几乎无法自我演化；但公司有生老病死并不可怕——新公司才有机会，年轻人才有梦想。
