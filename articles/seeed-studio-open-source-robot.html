深度洞察

01

18年开源之路：从硬件模块到机器人大脑

01:23 - 04:17
核心观点

Seeed Studio 从2008年起深耕开源硬件，18年间完成了从微控制器模块到全栈机器人解决方案的跨越，成为 NVIDIA 精英合作伙伴，定位为"最强大、最先进的机器人大脑"。

深度阐述
从微控制器到机器人

Seeed 最初专注于开源硬件模块，让全球创客低门槛使用基础电子元件。随着创客运动发展，用户自然提出更高需求——这些硬件能不能用在工业上？能不能做真正的项目？这种需求升级推动了 Seeed 从模块供应商成长为完整的机器人解决方案平台。

NVIDIA 精英合作伙伴

从 Jetson Nano 起步，逐步扩展到搭载 Jetson Orin 系列的高性能设备。Seeed 构建了完整的机器人产品线——从桌面级小型机械臂到高性能计算平台，同时拥有从感知到控制的全栈机器人组件。

社区驱动的生物进化模式

Eric 描绘了类似生物进化的图景：不是一家公司造出终极机器人，而是成千上万的创造者各自探索不同方向，相互竞争、相互进化，最终每个领域都会涌现出最优秀的方案。未来的机器人将是专业化的，由开源模型驱动，覆盖特定领域。

"它不再只是一台机器，而是一台能跟你对话、能被分配任务的机器。这正在形成一个全新的机器人社会。" — Eric Pan
02

开源为何是机器人的必由之路

04:17 - 08:09
核心观点

开源在机器人领域不仅是技术发展的加速器，更是建立用户信任和推动大规模采用的基石——你不会把一个黑盒机器人放进自己家里。

深度阐述
创新效率：生物多样性竞争

没人知道"终极机器人"长什么样。与其由一家公司闭门造车，不如开放出来让全球的创客、开发者、研究人员各自探索。这种多样性的竞争和协作，就像生物界的自然选择，能更快找到每个领域的最优解。

信任与可控性

这是更深层的驱动力。想象你要在家庭、工厂或零售店部署一台智能体机器人——你希望它是可控的，你希望能查看和修改它的行为逻辑。一个闭源的、被锁死的系统，很难获得这种根本性的信任。

从创客到企业的渗透路径

Seeed 的数百万客户中，大多数自称"创客"——爱好者、学生、研究人员。他们从兴趣出发，理解技术后将其带入各自行业——成为企业员工、创业者或大公司创新项目的核心力量。中小企业是增长最快的群体，因为开源工具第一次让他们拥有了以前只有大企业才负担得起的自动化能力。

"代替销售人员的，是创客和开发者——他们带着天然的好奇心去探索新事物，然后将其整合到自己的业务中。" — Eric Pan
03

200美元革命：SO-ARM 与 Hugging Face

08:09 - 10:02
核心观点

Seeed 与 Hugging Face 合作推出的 SO-ARM 以200美元的价格打破了机器人行业的价格底线，让"人人都能拥有一台机器人"从口号变为现实。

深度阐述
价格颠覆

传统工业机器人需要专业机器人学家进行漫长的编程、调试和维护，成本极其高昂，只出现在医疗和汽车等高价值行业。SO-ARM 将这个门槛压缩到了消费级——相当于一台入门级智能手机的价格。小孩子都能用。

从玩具到商业基础

在去年举办的黑客松中，参与者用 SO-ARM 做了做饭、烤肉等各种项目。对专业人士来说它可能像玩具，但 Eric 强调要尊重背后的潜力——当人们认真思考如何用廉价机器人在街边开店、探索各种可能性时，这其实正在发生。SO-ARM 是更高端机器人方案的根基，大量用户通过它学习、开发，逐步升级到更专业的应用。

04

训狗式教学：从数月编程到手把手示范

10:02 - 12:58
核心观点

机器人训练正在经历范式转变——从需要数月专业编程，变成像训狗一样的直觉式手把手教学，让厨师、铁匠等非技术人员也能直接训练自己的机器人。

深度阐述
五步工作流

全新的训练流程：(1) 手把手教学——像教一个学徒一样，握住机械臂示范操作流程几次；(2) 云端训练——将采集的示范数据上传训练；(3) 本地部署——训练好的模型部署到 Jetson；(4) 扩散模型执行——Jetson 使用扩散模型配合摄像头自主规划路径；(5) 迭代优化——执行不正确就重新训练。

增强而非替代

这个范式的意义远超技术层面。一个厨师、一个铁匠、一个小店主——不需要任何编程知识——就能训练一台专属于自己的机器人。Eric 精准地定义了这种关系：这是我的机器人，它是我的学徒，帮我做事情，但不会取代我。这不是"机器人替代人类"的叙事，而是"每个人都能拥有一个机器人助手"的新范式。

"这是我的机器人。它继承了我的技能，或者说它是我的学徒。帮我做事情，帮我的生意，但不会取代我。" — Eric Pan
05

OpenClaw：给 AI 一个物理身体

12:58 - 18:35
核心观点

OpenClaw 集成到 Jetson 后，实现了从"编程控制机器人"到"用自然语言对话控制机器人"的跨越——AI 智能体第一次真正拥有了一个可以操作物理世界的身体。

深度阐述
自然语言控制

在 Jetson Thor 上本地安装 OpenClaw，调用 Qwen3.5 模型的本地 API。用户只需在聊天框输入文字指令——"把机械臂抬起来"、"放下去"、"用爪子夹住"——机械臂就会直接执行。传统的机器人编程需要从感知层到控制层逐层硬编码，现在这一切被自然语言交互完全取代。

自主探索物理世界

大约两周前，Seeed 给了 OpenClaw 一个"野性"任务——让它自己去找库文件、读说明文档、把自己放到物理世界中。OpenClaw 自主完成了整个流程：搜索并组装库文件，理解"向上移动10厘米"这样的空间概念，规划执行路径。Seeed 实际上给了 OpenClaw 一个物理身体——不仅能理解世界，更能建造世界、移动物理世界中的物体。

机器人社会的分层架构

OpenClaw 的"灵魂"配置允许定义机器人的角色、能力和职责范围。更远一点看，Eric 描绘了分层的机器人协作架构：协调器（中央助手）管理所有机器人，AI监控摄像头观察并纠正错误，自动导引车（AGV）负责送料，机械臂按标准操作流程执行任务。每个机器人还可以有自己的子智能体，形成一个全新的机器人社会。

"我们实际上给了 OpenClaw 一个物理身体。不仅是帮你理解世界，而是帮你建造世界。" — Eric Pan
06

Isaac Sim 与数字孪生：仿真到现实的桥梁

18:35 - 25:16
核心观点

NVIDIA Isaac Sim 提供的数字孪生能力，让开发者在没有实体机器人的情况下就能完成仿真训练——当仿真到现实的差距被弥合，机器人开发的速度将呈指数级提升。

深度阐述
reBot Arm：1000美元的开源实用机器人

Seeed 最新发布的 reBot Arm（Redefine Robots）已在 GitHub 上获得超过1300个 Star。三个核心特点：(1) 开源——部分零件3D打印，所有设计文件公开发布；(2) 实用化——不是教学玩具，而是真正能做事情的工具；(3) 亲民价格——起步价1000美元，搭配 Jetson Nano 运行，所有计算在本地完成，不需要云端 API token。

数字孪生与 Sim-to-Real

reBot 在 Isaac Sim 中的镜像效果——机器人实体的每一个位置变化、每一个执行器的运动都实时反映在仿真环境中。在还做不到"每人一台机器人"的当下，先让更多人通过网络和仿真参与。完整工作流：在 Isaac Sim 中训练视觉-语言-动作模型（VLA）→ 部署到实际机器人 → 物理世界数据反馈回仿真 → 模型持续优化。

LeRobot 框架与五个月量产

Hugging Face 的 LeRobot 框架提供了完整的数据集、模型和策略，实现端到端学习。Seeed 与 Hugging Face 合作开发的 Reachy Mini——从设计到3000台量产发货，仅用了五个月，展现了惊人的制造执行力。

"我们正在搭建更多的「仿真到现实」和「现实到仿真」的桥梁。随着越来越多廉价、亲民的机器人出现，仿真与现实的差距将非常容易弥合。" — Eric Pan
07

模块化哲学：拆解人形机器人

25:16 - 29:00
核心观点

Seeed 选择了与"造人形机器人"截然相反的路径——不是造一个什么都能做的通用机器人，而是把机器人拆成头、手臂、轮子等模块，让人们根据需求自由组合。

深度阐述
参考设计而非最终产品

作为开源公司，Seeed 不期望自己的设计被原封不动地使用。用户总会问"我能不能改改？"。所以 Seeed 提供的是"参考设计"——一个起点和框架，开发者在上面构建自己的方案，然后回来要求定制和改进。Seeed 的核心业务就是帮助这些人规模化。

拆解人形机器人

Seeed 的产品线包括：机械臂、底盘、机械手、桌面机器人——全部兼容 LeRobot 框架。模块化方案的好处是：根据实际需求组合，不需要为用不到的功能买单；从最便宜的模块开始，逐步扩展；用户在实践中找到自己的"飞轮"——物理需求与硬件能力之间的正反馈循环。

有机创造的未来

Eric 对未来一到三年的展望：我们不再等待别人来造一个人形机器人——也许不信任它，也许等不了，也许太贵了。但现在每个人都能为自己造一台机器人。如果他们有一群相似需求的人，就有人可以基于物理 AI 创立一门生意。这更加有机。

"我们走了与做人形机器人相反的路。我们把人形机器人拆解了——我们造头部和躯干，造手臂，造轮子。人们可以根据自己的用途将它们组合起来。" — Eric Pan
