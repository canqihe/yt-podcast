AI 抛售与数据 背道而驰

2026年7月，大量AI股一个月内下跌40%-60%，市场恐慌得像"把2022年压缩进一个月"。但硅谷的地面数据却完全相反：GPU现货租金半年暴涨50%-60%、内存现货价飙升、token增长全面加速。顶级AI投资人 Gavin Baker 拆解这场"抛售与基本面背离"背后的真相——以及真正可能打破看多叙事的分水岭。

核心要点

01

基本面在加速，市场却恐慌

无论用 GPU 供应、租赁定价、DRAM 现货价还是 token 增长衡量，一切指标都在加速；市场恐慌的一大根源是它对 Anthropic、OpenAI 等关键私营实验室"没有可见度"。

02

GPU 涨价才是看多信号

现货 GPU 租金半年涨 50%-60%，说明所有已签约的超大规模平台都按远低于市价的老合同"少赚"，一旦合同滚动重定价，它们的经营现金流将大幅跳升。

03

算力可由经营现金流自给

若算力以合理速率重定价，超大规模平台经营现金流可达约 2 万亿美元，足以抹掉约 7000 亿美元的信贷需求，让"债务融资崩盘"这一最大空头叙事站不住脚。

04

token 就是 token

开源抢走的是前沿模型的利润率，而非算力需求——无论模型贵贱，生产一个 token 所需的 FLOPs 与瓦数完全相同，因此开源冲击恰恰是算力需求的催化剂。

05

打破 LTA 可能毁掉整家公司

在多点竞争的内存博弈中，违约换来的只是短期低价，却会在下一个供给周期失去所有配额——苹果时代"大买家为所欲为"的逻辑已不再适用。

06

监管是最大的风险

纽约已出台数据中心暂停令，而"数据中心抢水抢电抢工作"的叙事源于一个被高估 1 万倍的错误数据；AI 产业最急需讲好自己的故事。

有报告称 SpaceX 要带来 8 吉瓦算力，Gavin"几乎不敢信"，但他永远不与马斯克对赌——因为至今只有超大规模平台、CoreWeave、Crusoe 和 SpaceX 能在一年内上线超 500 兆瓦电力，而 SpaceX 是最快、最低成本的。若按每吉瓦约 500 亿美元变现，8 吉瓦对应约 730 亿美元（正是明年的共识预期），远超 Starlink 等业务"很快破百亿 ARR"的量级——这正是"SpaceX，这家数据中心公司"这个梗的合理性。

马斯克的名言是"我们专精于把不可能做到晚点交付"。Gavin 在星舰基地（Starbase）的切身体验是"轨道算力一天比一天更真实"——连不属于马斯克生态的 Benchmark 都被吸引去投了轨道算力公司 StarCloud（将与 SpaceX 合作使用 Starlink 激光技术），这让 Gavin 觉得"不是我疯，而是大家都不太可能同时发疯"。

SpaceX, the data center company. — "SpaceX？它其实就是一家数据中心公司。" Gavin Baker [01:15:38]

精华收获

🔄

认知升级

GPU 涨价才是看多信号。很多人以为算力降价利好 AI，真相相反——现货租金半年暴涨 50%-60%，恰说明所有超大规模平台都按老合同"少赚"，合同重定价后经营现金流会跳升。

📊

关键数字

1.3 万亿→2 万亿美元。若算力以合理速率重定价，超大规模平台经营现金流足以覆盖大部分建设，从而抹掉约 7000 亿美元信贷需求——让"债务融资崩盘"这一最大空头叙事站不住脚。

🧠

思考框架

token 就是 token。开源抢走的是前沿模型的利润率，而非算力需求；无论模型贵贱，生产一个 token 所需的 FLOPs 与瓦数完全相同。可用它看穿所有"开源稀释 AI"的误读。

⚖️

博弈陷阱

打破一份 LTA 可能毁掉整家公司。在多点竞争的内存博弈中，违约换来短期低价，却会在下一个供给周期失去所有配额——苹果时代"大买家为所欲为"的逻辑已不适用。

🚨

独立判断

警惕"AI 同质化"。当所有人把新闻喂给同一个 Claude 去解读，市场就失去了认知多样性——这正是泡沫与崩盘的结构性根源；保持独立判断，不要盲从单一 AI 的观点。

🚀

渗透之比

全球仅约 25 万-50 万人使用智能体式 AI，而算力已严重短缺；从 50 万到 1% 再到 5 亿的渗透曲线才刚起步——需求增长的坡道远比市场想象的长。
