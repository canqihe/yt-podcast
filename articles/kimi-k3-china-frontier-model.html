核心要点

01

三巨头已死

Google 已被踢出「AI 三巨头」俱乐部，Moonshot Kimi K3 取而代之。综合基准测试中排名全球第三，仅次于 Fable 5.6 和 Sonnet 4.6。

02

利润率惊人

K3 定价 ($15/$75) 可能已有利润，而 Fable ($50/$250) 是它的 3 倍以上——AI API 的毛利率高到令人难以置信，比 SaaS 还好。

03

开源逼近闭源

差距缩小的根本原因不是技术突破，而是美国政府对 Anthropic 的限制人为拖慢了前沿模型的公开发布速度。

04

工具链即护城河

当模型能力趋同时，工具链体验决定用户选择。「能不能装 SSH 服务器」「快捷键好不好用」这些细节胜过基准测试分数。

05

国产芯片生态

K3 兼容 11 家中国加速器——这是国家级战略。中国企业正在构建从芯片到模型的完整硬件-软件栈，独立于 Nvidia 生态。

06

AI 还极其早期

即使 AI 会议上 80% 的人也没听过 SemiAnalysis——行业渗透率远低于直觉，增量用户数量级远大于存量用户之间的分流。

深度洞察

01

Kimi K3 是第三好的模型吗？

00:11 - 04:04
核心观点

Kimi K3 在综合基准测试中明确排名全球第三——仅次于 Fable 5.6 和 Sonnet 4.6——这是一个里程碑式的成就，尤其是当它把曾经的前沿代表 Google 甩在了身后。

深度阐述
Max 开门见山

K3 毫无疑问是当今世界第三好的模型。虽然基准测试有局限性，但多年来模型排名的「方向性正确」一直经受住了考验。从综合数据看，前三名形成了清晰的梯队——Fable 5.6、Sonnet 4.6、Kimi K3——它们稳定地高于所有其他对手。

认知滞后

这个结论最令人震撼的不是 K3 有多强，而是公众对 AI 格局的认知严重滞后。Max 指出「就在 2025 年底，所有人都认为 AI 三巨头是 Google、Anthropic 和 OpenAI」，但今天 Google 已经跌出前三。

使用体验

Jordan 甚至给出了激进判断：对他个人而言，K3 可能是世界第二好的模型，因为「每次我想在 Fable 上做点有意义的事，它都拒绝我」。K3 虽然速度略逊，但至少不会被随意拒之门外——这种「可靠性溢价」非常真实。

"如果你看今天的综合排名，很明显前三名是 Fable 5.6、Sonnet 4.6 和现在的 Kimi K3。"

[01:05]

"Google 现在应该感到极其尴尬。"

[01:41]

02

为什么要延迟发布权重？

04:04 - 05:30
核心观点

Moonshot 在 API 上线和权重发布之间设置 10 天延迟，极有可能是为了给第三方推理服务商足够的时间优化部署性能，并可能在与 Together、Fireworks 等公司洽谈授权合作。

深度阐述
1. 性能保底策略

如果当天直接发布权重，所有第三方服务商都会蜂拥而上部署 K3，但准备不足会导致推理速度极慢（「每秒 20 个 token 可能都会不到」），这在品牌上是一个巨大的负面信号。

2. 商业授权谈判

Moonshot 很可能正在与 Together AI、Fireworks AI、Nebius 等开源模型服务商洽谈授权协议，让它们在最新的 GB300 等硬件上提供 K3 的推理服务。

"他们需要给 VLM 和 SGLang 的开发者足够的时间来确保能高效运行这个模型。"

[04:30]

03

2.8T 参数与服务限制

05:30 - 06:48
核心观点

K3 的 2.8 万亿参数规模意味着它无法在 B200 上运行，只能用最新的 B300、GB300 等芯片才能部署——这本身就给出了一条关于闭源前沿模型实际规模的宝贵线索。

深度阐述
模型架构门槛

2.8T 参数装不进单台 B200 设备，你需要 GB300 或者 AMD MI355X 才能在单台 8 路 HGX 服务器上运行。理论上可以通过跨节点流水线并行来部署，但这会严重影响推理性能。

闭源模型体量线索

如果 K3 在 2.8T 参数上就能和 Fable/Sonnet 正面竞争，那闭源模型不可能比自己大太多——「如果闭源模型真的有 10 万亿总参数，那大家真的可以收拾包袱回家了」。

"如果达到这个性能水平的模型被拿来和十万亿参数、激活参数更多的模型比较，那就更尴尬了。"

[06:32]

04

前沿利润率与 3 倍涨价

06:48 - 11:10
核心观点

K3 的定价（$15/百万输入 token，$75/百万输出 token）是 K2 的 3 倍多，但即便如此可能仍有利润——这反过来揭示了闭源模型（如 Fable，$50/$250）拥有惊人的毛利率，AI API 可能比 SaaS 还要赚钱。

深度阐述
利润率照妖镜

K3 的价格是每百万输入 token 15 美元、每百万输出 token 75 美元——和 Sonnet 同价位，但远低于 Fable（50/250）。如果 K3 在这个价位上都没有亏损，而 Fable 定价却是它的 3 倍以上——这意味着 Anthropic 和 OpenAI 的利润率可能「绝对惊人」。

定价空间有限

Moonshot 没有太多继续涨价的空间了——很多用户的需求用 GLM、MiniMax M3 等低价模型已经足够，K3 的定位更像是「开源拥趸的情怀选择」，而非大规模企业采购的性价比之选。

"按 API 价格卖 token，可能比 SaaS 还要好。没有员工成本，只有 GPU。"

[08:00]

05

新架构与未来方向

11:10 - 14:09
核心观点

K3 是一个全新的基础模型，使用了 Kimi Delta Attention 等创新架构，它在发布时就相当成熟，没有常见新模型的「粗糙感」。接下来几个月应该能看到 2-3 轮后训练迭代。

深度阐述
架构创新

K3 使用了 Kimi Delta Attention（增量注意力机制）、Potential Residuals（潜在残差连接）、Stable Latent（稳定潜变量）等技术，体量约是 K2 的两倍（2.8T vs 约 1.4T）。

Cursor 分道扬镳

Cursor 曾经基于 Kimi K2.5 训练了 Composer，但 K3 版的 Composer 大概率不会有了——Cursor 团队现在倾向于从头训练自己的模型。

定价预测

未来几个月会有 2-3 次后训练更新（K3.1、K3.2 等），定价预计保持稳定。如果有顶尖的 kernel 工程师能优化到接近 DeepSeek v4 的定价水平，「那会非常令人印象深刻，但考虑到这是个 3 万亿参数的模型，我有点怀疑」。

06

开源能否追上闭源？

14:09 - 19:51
核心观点

差距缩小的根本原因不是中国公司的技术突破有多快，而是美国政府对 Anthropic 和 OpenAI 的限制人为拖慢了前沿模型的公开发布速度。这个格局催生了独特的商业机会和政策悖论。

深度阐述
人工追赶

Jordan 的判断：「差距缩小，直接就是因为美国政府对 Anthropic 施加限制，导致我们拿不到它们真正最好的模型。」Fable 5.6 不是 OpenAI 训练过的最大的模型——「我认为他们还有一个更大的模型在某个地方」。

西方开源困境

西方市场至今没有一个「不烂」的开源模型。美国企业从风险管控角度出发，根本不会把专有数据交给中国的开源模型——即使逻辑论证可行，高管们也不会买账。

中国务实策略

习近平鼓励中国公司保持模型开源，因为中国政府希望下载权重并在自有服务器上运行。「我认为美国政府也应该采用完全相同的策略。」

"我认为这个差距缩小的直接原因就是美国政府对 Anthropic 施加限制，导致我们无法获得真正最好的模型。"

[14:13]

07

为中国加速器而生

19:51 - 22:57
核心观点

K3 从设计之初就考虑了在中国国产 AI 加速器上运行——从 SFT 阶段的 MXFP4/MXFP8 量化到兼容 11 家国产芯片厂商——这是一项国家级的战略布局。

深度阐述
11 家中国加速器

K3 兼容至少 11 家中国加速器厂商——华为昇腾、壁仞、燧原、摩尔线程等等。「让这些前沿模型在中国国产加速器上运行是中国的国家优先级事项。」

量化技术设计

K3 在监督微调阶段原生使用了 MXFP4 和 MXFP8 量化格式，号称「广泛的硬件兼容性」。这不是技术洁癖——这是为在中国国产芯片构成的非标准化硬件生态中运行而做的刻意设计。

"我列了 11 家中国加速器厂商名单。想了解更多，请订阅 SemiAnalysis 加速器模型。"

[19:52]

08

工具链就是产品

22:57 - 28:49
核心观点

当模型能力本身差距不大时，工具链——部署的便捷性、快捷键顺手度、命令编辑的功能——成了决定用户将 token 和预算投向哪里的关键因素。

深度阐述
工具链即产品

测试 K3 迫使 Jordan 认真研究 OpenCode、Hermes、Pi 等开源工具。「听起来很傻，但这些小功能真的会影响我把 token 花在哪里——也就是我的预算流向。」

基于结果的定价

大部分用户即使知道低价模型也能完成任务，仍然倾向于使用 Fable 等顶级模型——不是因为「需要」，而是「不怕花别人的钱」。这为基于结果的定价创造了绝佳的土壤。

用例远未穷尽

除了编程，视频生成、音频到音频、深度研究、机器人、世界模型等领域都有巨大的探索空间。AI 的用例远没有被穷尽。

"工具链本身就是产品的一部分。"

[23:05]

"对我来说，要找到这些模型搞不定的日常任务真的越来越难了。"

[22:42]

09

我们还很早期

28:49 - 31:39
核心观点

即使 Kimi K3 从 Fable/Sonnet 手中抢走了一部分用户，增量用户（那些还没认真尝试 AI 的人）的增长速度会完全覆盖这部分流失。AI 的渗透率还极低，天花板远未到来。

深度阐述
高渗透率用户价值

同样使用频率，Fable 用户比 Sonnet 用户多花 10 倍的钱，而利润率高达 90%。「一个人用 Fable 花 10 倍的钱，他们贡献了业务的大头。」

头部用户占比极低

Jordan 估计自己在全球 AI 用户中属于前 1% 甚至前 0.1%，当这些重度用户开始用更大模型时，他们用得更多，创造了更多需求。

渗透率极低

Max 去了 ICML 和 AI Engineer 两个「名义上的 AI 会议」，结果 80% 以上的人从未听说过 SemiAnalysis。AI 的渗透还极度早期。

"我会说 80% 以上的人从来没听说过 SemiAnalysis。我就想，兄弟，你们在干嘛？我们还太早期了。"
