核心要点

01

Token 盗窃是 AI 经济的隐形杀手

超过六分之一的 AI 公司注册是欺诈行为。在 AI 经济中，偷 Token 比偷钱更危险——因为每次推理都有真实成本，高欺诈率直接威胁公司生存。

02

智能体商务不是非黑即白

从人类完全自主到智能体完全自主，这是一个完整的谱系。无论你在哪个位置，都需要产品目录暴露、消费者授权、安全交易执行的新基础设施。

03

AI 正在重塑商业构成

新企业创办速度翻倍，增长完全由个体创业者驱动。美国已有 500 万人靠单人公司维持生计。AI 将创业门槛从「你会编程」降至「你有想法」。

04

部署是新的瓶颈

AI 解决了写代码，但没有解决让代码上线。当智能体可以在 20 分钟内写完完整应用时，注册数据库、配置 CDN、管理 API 密钥反而成了最大摩擦点。

05

微交易的黄金时代来了

智能体可以无缝执行微交易，人类不需要做任何操作。结合稳定币结算，将催生全新的 AI 支付经济——从 5 美分的文章到按量推理计费。

06

「微型企业」智能体即将到来

12 个月后，我们将看到第一批端到端自主运营的智能体——它们买、卖、集成、运营，成为真正的经济单元。这不是工具，是经济主体。

01

智能体电商的崛起

00:01:24 - 00:05:53
核心观点

过去一年，智能体作为买家已从假设变为已部署的基础设施。但其展开方式并非单一模式，而是涵盖一个完整谱系——从完全自主到人类辅助。

深度阐述
完整谱系

在谱系的一端是机器支付协议（MPP）——智能体完全自主发现服务、决定购买并执行交易；另一端是人类在 AI 界面中搜索产品、获得推荐后一键下单。

贯穿线

无论你在谱系的哪个位置，都需要一套全新基础设施：企业暴露产品目录，消费者授权智能体支付，智能体安全执行交易。

合作伙伴

Stripe 已与 Google（Gemini AI 模式）、Microsoft（Copilot）、OpenAI（ChatGPT）、Meta（广告结账）合作。Wix、Shopify、Big Commerce 等平台和 Best Buy、Coach、Kate Spade 等品牌已全面接入。

「当人们进行合理规模的交易时，这没问题。我认为我们会很快进入一个世界——在智能体商务和稳定币所支持的微交易的交汇处。」—— Emily Sands [00:03:17]

产品目录暴露

采用情况

Best Buy、Coach、URBN、Kate Spade 等零售品牌已上线；Wix、Shopify、Big Commerce 等平台已完成接入；Google、Microsoft、OpenAI 等 AI 玩家全面就位。

「我认为企业不会愿意只押注一个智能体界面。他们可能同时做 B2C 和 B2B，希望触达许多不同界面上的广泛消费者群体。」—— Emily Sands [00:07:40]

深度阐述
宏观数据

美国企业注册数量在疫情期间激增后曾趋于平稳，最近又开始加速。增长完全来自「非雇主企业」（non-employer firms），即个体创业者。

「自 2022 年以来，年收入超过 10 万美元的个体创业者数量呈直线上升。现在仅在美国就有 500 万人通过经营个人公司来维持生计。」—— Emily Sands [00:15:10]

信任：AI 商务的最大障碍

00:16:56 - 00:23:18
核心观点

技术基础已基本到位，但消费者信任需要时间建立——就像二十年前人们不敢相信在网上输入信用卡号一样。

深度阐述
信任技术层

Stripe 做了大量工作：共享支付令牌确保智能体永远看不到底层凭证；每个令牌都携带 Radar 评分实时评估；Link 钱包（3 亿用户）正在被改造为「智能体钱包」。

信任建立

在金融领域，没有人一开始就假设信任——必须去赢得它。Emily 类比电商早期历史：二十年前没人网上买床垫，如今网上购买的可能比实体店还多。

用户体验挑战

消费者目前主要用 AI 发现产品，但仍在亲自做购买决策。需要一个「魔法时刻」——让人确切知道可以把哪些事情完全卸载给 AI。

「基本上没有人一开始就假设信任。你必须去赢得它。」—— Emily Sands [00:19:42]

Link 钱包与共享支付令牌

00:23:16 - 00:29:59
核心观点

Link 钱包允许消费者授权智能体付款，同时提供细粒度控制——从单次交易的审批模式到预算、商家、地理限制的灵活配置。

深度阐述
演进阶段

第一阶段是「一次性虚拟卡」——极安全但极死板，只能用于单次、单商家、固定金额交易。第二阶段是 Link 钱包，提供更灵活的控制：预算上限、商家类别限制、单笔或累计金额审批。

支付原语

共享支付令牌是全新支付原语——编码了智能体的全部权限边界，支持卡以外多种支付方式（先买后付等），且与支付处理器无关。

整合价值

一个人可能有信用卡、借记卡、银行账户、稳定币等多种支付凭证。Link 钱包将所有凭证整合到一个统一的智能体钱包中，「使推理变得更加简洁」。

「你不是给智能体一张空白支票或无限访问你的活期账户。你明确地定义了它能做什么。而且你随时可以收回权限。」—— Emily Sands [00:23:47]

稳定币与微交易：AI 的微支付经济

深度阐述
人类交易的摩擦

微交易在互联网内容经济中从未成功——没人愿意为 5 美分文章掏出信用卡。买卖双方都亏。

当人类不需要输入凭证、导航页面、批准弹窗时，交易成本降为零。智能体替你完成一切，微交易变得可行。

通过与 Tempo 合作，使用稳定币即时结算，微支付在经济上变得可持续。在购买推理、AI SaaS 产品等场景中，用户将通过 Link 钱包进行大量微交易。

「微交易实际上从来没有太大的意义，即使在内容消费的背景下也是如此，因为没有人愿意——即使只有 5 美分——输入他们的信用卡去购买一篇 5 美分的文章。」—— Emily Sands [00:29:59]

深度阐述

Stripe Projects

「凭感觉编程很容易。凭感觉部署反而成了更紧的约束。」—— Emily Sands [00:40:13]

Token 如何颠覆 SaaS 计费模式

00:42:50 - 00:50:41
核心观点

传统 SaaS 边际成本近乎零，AI 的每次推理都有真实成本。AI 公司正从纯订阅转向「混合计费」——固定费用 + 按 Token 消耗收费。

深度阐述
模式转变

传统 SaaS 构建一次产品，边际成本近乎零，按席位订阅完美运作。AI 打破了这种模式——每一条提示、每一次 API 调用都有真实推理成本。客户的用量直接决定企业是赚还是亏。

混合计费

几乎没有规模化的 AI 公司仍使用纯订阅模式。解决方案是「混合计费」：每月固定费用（如 25 美元），包含一定积分，超出部分按实际消耗收费。Lovable、11 Labs 都走过这条路径。

流式支付

当买家是智能体时，传统月度计费也面临挑战——智能体可以以机器速度消费。Emily 预见「流式支付」：在 Token 消耗的同时实时计费和收款。

「AI 打破了这种模式，因为每一条提示、每一次 API 调用、每一个任务突然都有了真实的边际成本，这在 SaaS 中是没有的。」—— Emily Sands [00:42:50]

Token 盗窃：AI 经济中增长最快的欺诈

00:50:41 - 01:00:10
核心观点

超过六分之一的 AI 公司注册是欺诈行为。在 AI 经济中，偷 Token 比偷钱更危险——因为每次推理都有真实成本，高欺诈率直接威胁公司生存。

深度阐述
三种主要欺诈

多账户滥用：超过 1/6 的注册属于此类——欺诈者不断创建新账户获取免费积分。
免费试用滥用：过去六个月翻倍，已形成围绕「免费试用卡」的灰色产业。
用完就跑：积累数千美元费用后拒不付款。在 SaaS 时代被偷无所谓，但 AI 时代 Token 成本真实。

变现方式

批量生成音乐曲目上传 Spotify 骗版税；克隆整个 AI 公司——用凭感觉编程做网站，后端调用被窃取的服务，以更低价格出售。

快速响应

Stripe 与大型 AI 公司形成闭环：发现欺诈模式 → 几周内构建 API → AI 公司接入后实时获得评分 → 在登录、试用、用量累积时分别阻断。

「超过六分之一的 AI 公司注册属于这种滥用行为。」—— Emily Sands [00:52:26]
