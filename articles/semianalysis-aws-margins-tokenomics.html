核心要点

01

利润率分化

三大云服务商 AI 利润率走势截然不同——AWS 飙升 10 个百分点，Azure 下降，GCP 持平。Bedrock 的 Token 即服务模式是关键变量。

02

Token 即服务碾压 GPU 即服务

Token 即服务按使用量计费、收入无上限，而 GPU 租赁是固定费率合同。在 Anthropic 每月新增 100 亿 ARR 的拉动下，亚马逊的利润缓冲远超竞争对手。

03

云护城河崩塌

从三巨头垄断到 200+ 新兴云涌入，GPU 即服务的进入门槛远低于传统云。但 Token 即服务需要前沿模型合作和庞大客户基础，形成了新的壁垒。

04

Anthropic 一家驱动超预期

2026 年 AI 市场大幅超预期，但构成极度不均——前沿端几乎完全由 Anthropic 一家公司驱动。OpenAI、Google、xAI、Meta 均落后于预期。

05

赢家通吃的经济学

在开放式任务中（法律、科研、编码），最智能的前沿模型反而最便宜——因为完成任务所需 Token 更少。市场将高度集中到少数前沿玩家。

06

xAI 退出前沿竞赛

将算力租给 Anthropic、核心人才纷纷离开，SpaceX S-1 中宣称的 22.7 万亿美元 TAM 与其实际战略选择形成讽刺对比。

深度洞察

01

Bedrock 与三大云服务商的业务图谱

00:00 - 02:40
核心观点

超大规模云服务商的 AI 业务分为三大类：AI 软件即服务（如 GitHub Copilot）、AI 基础设施即服务（出租 GPU 芯片）、以及 Token 即服务（通过云平台提供模型推理）。三种模式的利润率截然不同，而 Anthropic Claude 通过 Bedrock 托管是 AWS 利润率飙升的核心驱动力。

深度阐述
三种业务模式的差异

微软的 GitHub Copilot 代表 AI 软件即服务——产品化程度最高。基础设施即服务是最传统模式：客户租用 GPU 自行运行工作负载。Token 即服务是近年兴起的新模式，客户通过云账户购买模型推理能力，无需管理底层硬件，同时享受安全性和可用区域等企业级保障。关键区别在于利润率——出租底层 GPU 是固定费率的「管道」业务，而卖 Token 则包含模型推理的溢价空间。

Anthropic 增长的催化作用

SemiAnalysis 文章的核心发现：亚马逊对 Anthropic Claude 的 Bedrock 托管正在成为其 AI 业务利润率飙升的核心驱动力。两大关键因素——Anthropic 的快速增长和亚马逊围绕 Bedrock 的战略——共同推动了 AWS 利润率的提升。

02

AWS 利润率逆势攀升

02:33 - 03:33
核心观点

2025 年第一季度，AWS 大幅上升运营利润率，微软 Azure 下降，谷歌云持平。云使用量整体增长，但关键区别在于使用量通过谁的路由——AWS 受益于 Anthropic Claude 大量 Token 消费走 Bedrock 渠道。

深度阐述
工作负载组合决定利润率

当 Azure 和 GCP 的 AI 收入仍然主要依赖 GPU 租赁时，AWS 正在将越来越多的 AI 收入转化为 Token 服务收入。这种结构性转变意味着：即使三家都在疯狂建设数据中心和购买 GPU，只有 AWS 能在产能扩张的同时提升利润率。Bedrock 的 Token 即服务模式天然比纯基础设施出租有更好的利润率。

03

云护城河的崩塌：从三足鼎立到 200+ 新玩家

03:33 - 06:32
核心观点

AI 时代云计算进入门槛大幅降低——从 2022 年前三家垄断到超过 200 家新兴云涌入。传统云的护城河正在瓦解，而 Token 即服务是第一个在大规模上展现不同商业特征的 AI 云业务模式。

深度阐述
GPU 标准化打破垄断

2022 年及以前，云服务市场几乎由 AWS、Azure、GCP 三足鼎立，拥有极高利润率和资本回报率。但 GPU 即服务的兴起彻底改变游戏规则——当 GPU 成为标准化商品，任何人只要有资本就能搭建 GPU 集群出租。Jordan Nanos 认识超过 200 家新兴云 CEO。大型终端用户也从平台即服务转向裸金属需求——OpenAI、Meta、微软都想按自己的方式使用硬件。

Oracle 和 CoreWeave 的困境

Oracle 的剩余履约义务高达半万亿美元，一度超过亚马逊，但市场不给高估值——投资者清楚这种收入的风险性和低回报率。CoreWeave 等纯 GPU 即服务公司面临「稳定化滞后期」困境：数据中心建设是巨大前期资本支出，集群上线需要数月，GB200 等新型设备部署周期更长。在滞后期内，资产折旧、租金支付，但收入为零。

亚马逊的逆势扩张

亚马逊史无前例地在每季度 1 吉瓦产能扩张中实现利润率提升。如果在加速产能交付期间能扩张利润率，这意味着其稳定状态下的利润率将极为丰厚。

04

Token 即服务的稳定利润率为何如此丰厚

06:32 - 09:54
核心观点

Token 即服务的稳定利润率远超 GPU 即服务——纯 GPU 租赁业务的稳定运营利润率约 25%、毛利率 30%-40%，但亚马逊通过 Bedrock 卖 Token 有额外利润缓冲，不受 5 年期照付不议合同的上限约束。

深度阐述
收入模式的根本差异

纯 GPU 即服务是 5 年期照付不议固定费率合同——收入可预测但上限封顶。Token 即服务按使用量计费，收入随客户使用量增长而增长，没有上限。当客户是 Anthropic 这样每月新增 100 亿 ARR 的公司时，这个「没有上限」就变成了巨大的利润来源。

产能利用的时差优势

从建设数据中心到 GPU 集群全面运营的滞后期因 GB200 等复杂设备而拉长。纯基础设施提供商在「黑暗期」里只有支出没有收入。而亚马逊通过 Bedrock 的 Token 服务模式，新 GPU 上线后立即转化为 Token 推理产能——Anthropic 的需求如此旺盛，产能几乎即插即用。

「亚马逊基本上是第一个在史无前例的产能扩张期实现利润率扩张的云服务商。如果在加速产能交付期间他们能扩张利润率，你就要开始思考：这个业务的稳定利润率会是多少？」— Jeremie [05:43]
05

亚马逊的工作负载组合优势

09:54 - 12:41
核心观点

亚马逊的优势不仅是 Bedrock 平台，更在于 20 年积累的庞大企业客户基础、与 Anthropic 的独家合作以及 Trainium 自研芯片的成本优势。Anthropic 80%-90% 的云业务走 Bedrock，而 OpenAI 60% 收入来自消费者订阅。

深度阐述
客户基础与购买习惯

AWS 拥有 20 多年积累的庞大企业客户基础。客户已习惯通过 AWS 购买从基础设施到应用软件的一切——MongoDB、Snowflake 等都通过 AWS Marketplace 分发。当 Anthropic 的 Claude 通过 Bedrock 提供，企业客户不需要改变任何购买习惯。

Anthropic vs OpenAI 的业务结构

Anthropic 约 80% 净增 ARR 来自 API 业务，编码是绝对主力，金融服务是第二大垂直行业。相比之下，OpenAI 第一季度 60% 收入来自消费者订阅——更不稳定、更难预测。亚马逊在对的时间遇到了对的伙伴。

Trainium 2 的交易结构

通过 Trainium 2（亚马逊自研 AI 芯片），双方获得了有吸引力的交易结构。Anthropic 为基础设施付费，同时双方有收入分成和利润分成条款。当 Anthropic ARR 从 2024 年 Q2 约 600 万飙升到 2025 年 Q1 约 2500 万时，这笔交易对双方都极为划算。

06

Anthropic 的预测与 Opus 4.8 发布

12:41 - 16:33
核心观点

预测 Anthropic 的增长比预测 OpenAI 更容易——其收入主要来自 API 消费而非消费者订阅，Token 消费数据相对透明。Opus 4.8 和 4.7 保持了 Token 定价稳定，但快速模式定价有调整，幻觉率据称显著降低。

深度阐述
预测方法论

由于 Anthropic 大量收入来自 API，SemiAnalysis 对其披露的收入和利润率预测相当准确。相比之下，OpenAI 收入主要来自消费者订阅，用户随时可取消，预测难度高得多。编码市场的规模仍是行业最大问题之一——金融服务是第二大垂直行业，但与编码的 API 支出差距仍然很大。

Opus 4.8/4.7 的改进

定价保持不变，但快速模式定价有所调整。更重要的是据称新模型的幻觉率显著降低——如果属实，对需要精确数值的分析工作将是重大改进。Fortune 500 强企业正在学习如何为 Token 消费做预算、衡量 ROI，这个过程仍在早期阶段。

SpaceX 算力交易与 650 亿美元 H 轮融资

看涨还是看跌？当需求方变成供给方

19:30 - 28:55
核心观点

SpaceX-XAI 与 Anthropic 的算力交易引发激烈辩论：一个前沿 AI 实验室把 GPU 租给竞争对手，这是看涨还是看跌？答案取决于你如何理解「训练前利润」以及 AI 市场是赢家通吃还是百花齐放。

深度阐述
Jordan：看涨逻辑

Anthropic 的需求旺盛到必须从竞争对手购买算力。合同中的 GPU 收回条款说明 xAI 保留了未来重返前沿竞赛的选择权——他们是一个能产生现金的新兴云业务，可以顺便做研究，未来有突破时再把算力投入。Meta 看到 Anthropic 的表现后会更加坚定投入，因为它有数百亿美元自由现金流来支撑长期研究。

Jeremie：看跌逻辑

xAI 基本上在退出前沿竞赛。当最顶尖的人才纷纷离开，同时你又把算力租给竞争对手，这两件事相辅相成地说明他们已经出局。SpaceX 没有 Meta 那种产生数百亿美元自由现金流的业务来支撑算力研究投入，必须依赖风险投资——而在数百亿美元规模下，风投资金是有限的。

Joey：技术视角

训练算力的回报是巨大的，但前提是有顶尖人才。没有算力意味着相对竞争对手处于劣势。开源模型和前沿模型之间的差距正在扩大而非缩小——去年流行的「开源会追上」叙事并没有发生。任何在生产环境中使用过的人都能感受到 Claude 和 DeepSeek V4 之间的差距。关于「5 倍算力能否弥补差距」的思想实验——结论是不能，你需要同时拥有算力和人才。

「开源对阵前沿——差距在扩大而不是缩小。去年大家都在说开源会赶上，但这没有发生。前沿模型大幅超越开源模型。」— Joey [26:48]

22.7 万亿美元 TAM：竞赛还重要吗？

28:55 - 31:59
核心观点

SpaceX S-1 宣称 22.7 万亿美元企业 AI 应用 TAM，但竞赛的胜负取决于你能否在开放式任务中提供最便宜的解决方案——前沿模型恰恰因为更智能，反而是最便宜的选择。

深度阐述
有限任务 vs 开放式任务

AI 任务分为两类：有限任务（如翻译，达到某个水平后花更多钱没意义）和开放式任务（如法律、科研、医疗保健、数据分析——想打败对手就要花更多钱获得更强智能，支出几乎无限）。开放式任务将驱动大部分 AI 支出。

成本效率悖论

Mythos 的 Token 定价是 Opus 的 5-6 倍，但如果它聪明 10 倍、完成任务所需 Token 少 10 倍，那用更贵的前沿模型完成任务实际上更便宜。这解释了为什么市场会集中到前沿模型——在开放式任务中，最智能的模型反而是最具性价比的。

当前排名与 Cursor 的崛起

按实际使用体验排名：Anthropic 第一（编码即计算机使用），OpenAI 第二，Cursor 第三。Cursor 的崛起说明分销渠道也很重要。有四到五家美国实验室从不同角度测试策略——有的有算力有收入，有的有算力没收入，有的有收入没算力。对 Anthropic 来说，捍卫第一的位置将是全新挑战——之前只需要追赶，现在要防守。

训练前利润与赢家通吃

31:59 - 36:27
核心观点

2026 年 AI 市场的超预期构成极度不均——基本全部由 Anthropic 一家公司驱动。即使开源端有 Fireworks（3.15 亿 ARR）、Cursor（20 亿 ARR）等亮点，相对于 1000 亿美元以上的市场规模，仍微不足道。

深度阐述
训练前利润（EBIT）概念

将训练和研究视为资本支出后，推理产生的现金运营利润就是「训练前利润」。Anthropic 显然在其编码和计算机使用模型上获得了巨大的投资资本回报率。而 Meta 除了推荐系统外几乎没有 AI 模型收入回报，xAI 的 Supergrok 只有约 100 万订阅者。

超预期的构成分析

在前沿端，只有 Anthropic 大幅超预期。谷歌的 Gemini 采用率落后，OpenAI 也落后。xAI 和 Meta 基本毫无存在感。开源端有一些采用增长，但以美元计仍然微乎其微。当超预期几乎全部由一家公司驱动时，这强烈暗示市场是赢家通吃的。

其他玩家的规模对比

Fireworks 声称 3.15 亿 ARR——相对于 1000 亿美元以上的市场规模只是四舍五入的误差。Cursor 约 20 亿 ARR，增长很好但也不大。在推理业务方面，除了前三名超大规模云服务商之外，其他都只是零头。AWS 的 Bedrock Token 即服务到年底可能成为其 AI 业务的主体部分。

「当超预期几乎全部由一家公司驱动时，这强烈暗示市场是赢家通吃的——如果你是最先进的，你获得大部分份额；如果你不是，人们不会在你身上花钱。」— Jeremie

谁是长期赢家：芯片、合作还是整合？

36:27 - 43:34
核心观点

长期来看，Token 即服务的赢家需要三个要素：前沿模型合作关系、庞大企业客户基础、自研芯片成本优势。终端用户完全不关心底层是什么芯片——只关心 Token 的质量和价格。

深度阐述
新兴云的致命劣势

成为成功的 Token 即服务业务的关键是：与前沿实验室建立合作关系，获得前沿模型访问权。Nebius、CoreWeave、Iron 等公司没有这些合作关系，也没有足够资本在没有长期合同保障的情况下部署 GPU。CoreWeave 或 Iron 的大部分业务都是多年期合同锁定，而亚马逊可以自由地投机部署，选择没有 5 年期照付不议合同锁定的需求。

自研芯片的利润率优势

AWS 有 Trainium，GCP 有 TPU，而 Azure 几乎全部依赖英伟达。在 Token 即服务模式下，自研芯片的垂直整合优势在利润率端体现尤为明显。随着推理效率提高，前沿实验室的推理毛利率过去两年大幅改善——同样的 Token 可以产生更高利润。

芯片透明化趋势

过去对芯片创业公司、TPU、Trainium 的批评都是关于可用性。但如果 Rainier 上 1 吉瓦的 Trainium 全部只是在为 1 到 3 个模型提供 Token 服务，终端用户根本不需要知道运行的是什么芯片。当 Jordan 使用 Claude Code 时，完全不知道 Token 来自 TPU、Trainium 还是 GPU——对用户来说只关心结果。这对英伟达的长期定价权构成潜在挑战。

编码不是「编程」，而是 AI 与计算机交互的接口——人类能用电脑做的一切，AI 也能做。Anthropic 凭借在编码领域的绝对优势，不仅赢得了开发者，更赢得了整个 AI 应用的入口。

赢家赢了，输家输了

2026 年的 AI 基础设施市场传递的信号非常清晰：Token 即服务的经济学正在重写云服务商的竞争格局。AWS 凭借与 Anthropic 的战略合作和 Bedrock 平台，在产能扩张的同时实现了利润率提升——这在 GPU 即服务时代被认为是不可思议的。而那些缺乏前沿模型合作和庞大客户基础的新兴云，无论拥有多少 GPU，都只是在参与一场利润率不断被压缩的商品化竞争。

「如果你是最先进的，你获得大部分份额；如果你不是，人们不会在你身上花钱。」
