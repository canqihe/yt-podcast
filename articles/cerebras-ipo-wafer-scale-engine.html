深度洞察

01

从「方案找问题」到「问题找上门」

00:05 - 05:45
核心观点

Cerebras 完成了从中东资本依赖到前沿 AI 实验室的战略转型。OpenAI 和 Amazon 两个蓝筹客户彻底改变了公司的商业叙事——从「方案在找问题」变成了「问题终于找上门来」。

深度阐述
客户集中度逆转

2024年提交 S1 文件时，Cerebras 几乎100%的收入来自中东的实验室和研究机构——G42 和 MBZ 大学。投资者对这种客户集中度深感忧虑。但短短一年内，OpenAI 签下了分三批交付、总计750兆瓦的令牌即服务协议（可扩至2吉瓦），Amazon 计划在 Bedrock 平台上用分离式推理架构——Trainium 做预填充，Cerebras 晶圆做解码——来服务 Anthropic 的模型。

性能数据碾压

团队在测试中发现，Cerebras 在 OSS 12B 模型上跑出了每秒1100个令牌的速度，而 InferenceX 基准测试中所有 Nvidia 和 AMD GPU 在交互式推理场景下的天花板是每秒500个令牌。CEO Andrew Feldman 用互联网带宽做类比：给我100兆宽带还倒贴钱我都不要，我要千兆以上的。

行业共振

就在 OpenAI 交易宣布的同时，Nvidia 收购了 Groq——同样的 SRAM 路线，不同的执行方式。两条路都指向同一个结论：快速令牌的需求是真实存在的。CEO Feldman 的赌注是：未来所有人都会嫌弃慢速令牌，就像今天没人愿意用拨号上网一样。

「之前几乎100%的收入都来自中东的实验室或研究机构，但现在有了真正的前沿实验室在使用 Cerebras。这是一个巨大的转变，问题终于找到了他们能真正解决的方案。」— Howie [00:04:21]
02

晶圆级引擎——革命性拼接与良率恢复

05:44 - 10:44
核心观点

Cerebras 的核心技术壁垒在于「革命性拼接」——将84个光罩图案无缝拼接成一片完整晶圆，并通过智能路由绕过缺陷，实现可用的晶圆级芯片。一片晶圆相当于84个芯片在同一网络中，无需离开晶圆。

深度阐述
光罩极限与拼接创新

ASML 光刻机每次只能在26×33毫米的区域内进行图案化（光罩极限）。Cerebras 在一张晶圆上排列84个光罩图案，通过与 TSMC 合作开发的特殊方法，上层金属布线层以特定方式连接，使相邻裸片之间不仅水平和垂直互联，还能绕过制造缺陷进行路由。否则，一个灾难性缺陷就意味着整片晶圆报废。

极小核心降低损失

Cerebras 的每个核心只有约200×200微米，远小于 Nvidia SM 的约6平方毫米。一个缺陷在 Nvidia 上意味着损失整个 SM，在 Cerebras 上只损失极小一部分。晶圆上约97万个核心，只启用90万个，有超额配置来保证良率。

智能路由保持网格完整性

当某个核心出现缺陷时，路由系统会自动将整个网格偏移一个核心的位置。从软件视角看，拓扑结构仍然是一个没有缺口的连续二维网格。软件完全不需要感知哪个核心坏了。这种设计的根本优势在于数据移动效率——AI 计算最大的瓶颈不是计算本身，而是数据在不同芯片之间移动的延迟和功耗。

「最高效的数据传输方式就是留在芯片内部。即使是 HBM 或通过 CoWoS 封装的 Chiplet 方案，也不如留在裸片内部高效。」— Myron [00:07:16]
03

供电、冷却与机械工程的极限挑战

11:03 - 13:35
核心观点

25千瓦的功耗、硅与 PCB 的热膨胀差异、直接在晶圆上钻孔——Cerebras 为了让晶圆级芯片成为可用的产品，在机械工程上付出的创新不亚于芯片设计本身。

深度阐述
垂直供电——业内首创

晶圆被垂直放置在系统中，电力从一侧垂直于硅片方向输入。这是业内第一个真正意义上的垂直供电实现。传统芯片的电力通常通过 PCB 基板从底部送入，但25千瓦的功耗让传统方式完全不可行。这套设计从2018年沿用至今。

柔性连接器应对热膨胀

硅的膨胀系数与 PCB 不同——晶圆加热和冷却时的形变会破坏刚性连接。Cerebras 开发了专有的柔性连接器，引脚可以活动，确保在热循环过程中电气连接不断。

直接冲击冷却与晶圆钻孔

复杂的冷板将冷却水分配到84个裸片上，直接向下进行冲击冷却。更令人惊讶的是——为了获得足够的安装压力，需要在有源晶圆上钻螺丝孔。在满是97万个核心的活硅片上钻孔，稍有不慎就会让裸片裂开。这个过程目前由 Cerebras 在加州自己的工厂里手动完成，速度很慢，无法轻易加速。

「瓶颈是钻孔。你不能说『给我快10倍钻孔』，这是一个缓慢的过程，他们非常小心不让裸片裂开。在有源晶圆中间钻孔——这是他们独特的挑战。」— Howie [00:21:05]
04

带宽困境——晶圆边缘的 IO 天花板

13:35 - 16:13
核心观点

晶圆级设计的物理约束使得 IO 带宽远低于现代加速器。只有晶圆边缘能输出信号，且84个裸片必须采用统一图案，导致 IO 面积利用率极低。当前1.2 Tbps的带宽是2018年设计决策的遗留。

深度阐述
三大物理限制

限制一：数据只能从晶圆的北面和南面通过特殊 FPGA 输出，中间的裸片无法直接对外通信。限制二：不能在同一张晶圆上图案化不同的光罩——所有84个裸片必须是同一套设计，如果每个都预留 IO 面积，中间72个裸片的 IO 面积就完全浪费。限制三：在裸片中间放置 IO 元素会干扰二维路由网络，增加布线复杂性。

未来路线图

Cerebras 目前不太愿意改动从 CS1 到 WSC3 一脉相承的核心架构。但远期路线图包括光学晶圆（Optical Wafer）和晶圆级中介层等更激进的方案，可能从根本上改变 IO 格局。

05

扩展之路——SRAM 缩放停滞与制造瓶颈

16:09 - 22:47
核心观点

Cerebras 面临双重扩展难题：SRAM 缩放停滞限制了片上内存增长，而独特的组装工艺（尤其是晶圆钻孔）限制了产能爬坡。但意外的是，不依赖先进制程反而成了供应链上的优势。

深度阐述
SRAM 缩放停滞的现实

晶圆级引擎上约50%的面积是 SRAM，而 SRAM 的微缩已经基本停止——从5纳米到3纳米密度几乎没有提升。Cerebras 自己也承认了这一点：下一代系统 CS4 将继续使用5纳米的 WSC3 晶圆。替代路径包括：提高面积效率（预计提升20-30%）、垂直 SRAM（类似 AMD 3D V-Cache）、未来3D RAM（位密度可达 SRAM 的10-15倍）。

因祸得福的供应链优势

不迁移到3纳米反而成为意外优势——当所有其他公司都在抢 TSMC 的3纳米产能时，Cerebras 可以从容地在5纳米上扩大生产。而且没有 HBM 和 CoWoS 的依赖，供应链更加简单。TSMC 供应晶圆完全不是问题，光罩拼接技术并不比 CoWoS 中介层更复杂。

组装瓶颈与数据中心挑战

真正的瓶颈在组装环节——Cerebras 在加州有自己的组装工厂，负责专有连接器安装和晶圆钻孔，这些工艺无法简单加速。同时，Cerebras 正在成为自己的「新云」（NeoCloud），需要操心数据中心空间、运维团队、电力和冷却的建设——对一家硬件公司来说是全新的挑战。

「不迁移到3纳米反而像是因祸得福——他们能在5纳米上从数百片扩展到数千片，不会遇到供应链瓶颈。而且没有 HBM 和 CoWoS，扩展相当容易。」— Myron [00:19:29]
06

OpenAI 的750兆瓦赌注

22:47 - 24:25
核心观点

Cerebras 与 OpenAI 的750兆瓦交易以令牌即服务模式交付，意味着 Cerebras 拥有类似 Amazon Bedrock 的上行收益——软件优化可以直接转化为利润增长。

深度阐述
交易结构与经济逻辑

750兆瓦分三批各250兆瓦交付，OpenAI 还有期权将交易扩大到2吉瓦。定价模式是按令牌计费而非卖硬件。签约时每百万令牌的售价必须覆盖运营成本，但在五年合同期内，软件优化让同样数量的晶圆产出更多令牌，收入不变但成本下降——利润率持续提升，与 Amazon Bedrock 的经济学非常相似。

风险与关键变量

Cerebras 承担了全部基础设施风险——建设数据中心、采购电力、部署运维团队。OpenAI 是否行使2吉瓦的期权，取决于第一批250兆瓦的令牌交付经济性。这是对一家此前专注芯片设计的公司的巨大战略跃迁。

「他们有750兆瓦与 OpenAI 的交易，OpenAI 有权将交易扩大到2吉瓦。关键问题是他们交付令牌的经济性如何，这将决定 OpenAI 是否行使期权。」— Jordan [00:24:25]
07

快速令牌的技术逻辑——低算术强度与 Roofline 图

27:56 - 32:43
核心观点

SRAM 机器的核心价值在于高效运行极低算术强度的核心——这正是 LLM 推理解码阶段的特征。在这个领域，GPU 不管加多少块都无济于事。

深度阐述
算术强度与 Roofline 图

算术强度衡量每移动一个字节数据需要做多少次浮点运算。高算术强度的例子是大型矩阵乘法——计算单元被充分利用，传统 GPU 表现优秀。但 LLM 推理的解码阶段是极低算术强度的——每次只处理一个令牌，计算量很小，但需要频繁读取模型权重。就像用一辆大卡车送一个快递，卡车再大也没用。

GPU 的物理天花板

在 Roofline 图上，低算术强度的工作负载碰到内存带宽的「屋顶」。不管堆多少 GPU——8个 H100 或72个 GB200——解码批次为1的场景下性能并不比单个芯片好多少，网络开销和内存带宽瓶颈抵消了更多计算资源。

SRAM 的根本优势

Cerebras 的 SRAM 架构从根本上解决了这个问题。整个模型权重存储在片上 SRAM 中，不需要从外部内存读取。解码时每个核心只需负责一小部分权重的计算，数据在片上网格中高速流转，无需离开晶圆。这就是每秒1100个令牌的秘密——GPU 在这个场景下根本无法企及。

「SRAM 机器的概念就是它们能做到其他方案在任何价格下都做不到的事情——运行低算术强度的核心。」— Howie [00:30:12]
08

万亿参数模型的现实——不可承受之重

32:40 - 37:46
核心观点

运行万亿参数模型在 Cerebras 上的前期投入至少1亿美元起步，而同等预算用 GPU 集群可获得更多内存和部署灵活性。中小模型才是当前最甜蜜的市场。

深度阐述
DeepSeek V4 实测估算

单个 Cerebras 系统资本支出约100万美元。用4位权重量化、16位 KV 缓存，支持256个并发用户在智能体编程工作负载下处理100万令牌上下文，需要24个系统——总计2400万美元，相当于8个机架。这只是运行一份模型的价格，实际可能需要多份。

GPU 的性价比优势

同样1亿美元可以买很多 GB300 NVL 机架，获得更多内存容量来运行多份模型、支撑更多 KV 缓存和更大的上下文窗口。更根本的问题是开发者生态——优化模型在特定硬件上的性能需要反复实验，1亿美元的硬件入门门槛让愿意且有能力的客户极其有限。

当前的真实市场定位

目前最清晰的公开使用案例是 GPT-5.3 Codex Spark——约120亿参数模型在128K上下文范围内运行。无论是 OpenAI 还是 Anthropic，今天都没有在晶圆上运行前沿万亿参数模型。但中小模型、中小上下文范围的快速推理是一个已经证明可行且规模可达数十亿美元/年的市场。

「投入晶圆技术的前期投入可能最低也要1亿美元起步。开发者需要接触这些系统来优化模型，如果入局门槛是2500万到1亿美元，有能力探索的客户就有限。」— Jordan [00:34:55]
09

快速令牌的定价上限——谁为10倍速度付100倍价格？

37:46 - 42:12
核心观点

快速令牌的定价面临天花板。当前 Anthropic 快速模式速度不到2倍却收6倍价格。10倍速度能否收10倍甚至50倍的价格，取决于应用场景能否证明其价值——或者说，取决于「下行保护」的定位逻辑。

深度阐述
当前定价的现实

从 OpenRouter 数据看：标准模式下 Google Vertex 的 Opus 4.6 吞吐量约每秒45个令牌，Amazon Bedrock 约38个令牌/秒。Opus 4.6 快速模式平均66个令牌/秒——速度不到2倍，价格是6倍。SemiAnalysis 认为 Anthropic 在快速模式上的利润率相当健康。Jensen Huang 声称10倍速度将对应「超线性定价」——100倍甚至1000倍的价格。

支付意愿的天花板

以每小时43美元租用一片晶圆，需要42片来运行一份模型，需要极高并发率才能把每百万令牌售价降到用户可接受的水平。一个每天花1000美元的开发者可能愿意为快速模式花6000美元，但不会花10万美元。超线性定价论点最终会遇到「世界的钱是有限的」这个硬约束。

下行保护的定位逻辑

快速令牌的价值可能在速度之外——如果它能解锁全新的交互模式（实时协作的 AI 编程助手、毫秒级响应的智能体循环），付费意愿可能改变。更妙的定位是「下行保护」：对于前沿 AI 实验室，如果快速令牌成为竞争关键，错过这艘船的机会成本可能远超为 Cerebras 付的钱。这时候定价逻辑就从「性价比」变成了「保险费」。

「如果你的业务定位是确保前沿实验室不错过快速令牌这艘船的下行保护，这是一个非常有趣的位置。」— Howie [00:41:51]
