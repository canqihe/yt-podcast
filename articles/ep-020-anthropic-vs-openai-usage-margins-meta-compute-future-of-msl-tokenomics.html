核心要点

01

订阅套利

每月 200 美元的 AI 订阅可换得 8,000–12,000 美元的 API 等价额度——用量超过 10% 就超出实验室的盈亏平衡点。实验室拼命推动大客户走 API 计费。

02

编程主导

编程占 API 收入 70% 以上，AI 商业价值高度集中在软件工程场景。Top 1% 超级用户每人每年花费 10 万美元，企业所有其他节流措施都杯水车薪。

03

Anthropic 利润惊人

80%+ API 收入占比，毛利率超 85%，Q2 实现运营盈利，Q3 利润可能超 10 亿美元。对比 OpenAI 因 9.5 亿免费用户被拉低约 20 个点毛利率。

04

OpenAI 绝地反击

年初增长停滞的 OpenAI 靠 GPT-5.6 和 Codex 强势回归。5.6 被评价为与 Fable 同样出色但价格只有一半，净新增 ARR 已与 Anthropic 持平。

05

算力回收条款

xAI 的 90 天算力回收条款模式：短期 3–4 倍市场价变现，一旦证明自己达到 frontier 即可收回算力。Meta 的 NeoCloud 策略类似，Google 因缺乏回收能力排在第五。

06

RL 数据新产业

强化学习数据市场 2026 年预算超 100 亿美元，实验室不计代价采购。单个高质量编程任务报价五位数美元，顶尖人才年入七位数。

深度洞察

01

紧缩政策的全面误区

00:00:53 — 00:03:05
核心观点

企业在 AI 代币预算上的紧缩政策大多不得要领——真正的浪费源自管理策略而非模型选择，而多数普通员工用量远未触及预算上限。

深度阐述
荒谬的限制

企业强制要求销售团队用 Sonnet 而非 Opus 写邮件——Max Kan 直言这毫无意义，因为生成一封邮件消耗的代币几乎可以忽略不计。更严重的是有些公司建立了「阶级制度」：只有工程团队能用高端工具，其他人只能用功能受限产品。这既不能控制成本，也剥夺了非工程岗位提升生产力的机会。

聪明企业的套利策略

小型企业找到了更聪明的方式：用便宜模型预处理和浓缩信息，再用昂贵模型做最终推理；或利用公司尚未纳入预算系统的模型来规避限制。这种「监管套利」揭示了企业在制定 AI 使用政策时面临的普遍混乱——企业内部甚至不清楚哪些模型应计入预算。

我完全不明白你们为什么要用这样的政策来减少代币开销。 Max Kan [03:33]
02

订阅计划：实验室的隐形成本

00:06:42 — 00:10:44
核心观点

AI 订阅计划的补贴程度远超想象——每月 200 美元可获得价值 8,000–12,000 美元的 API 额度，高等级订阅对实验室来说可能本身就是亏损的。

深度阐述
盈亏平衡分析

Claude Max 20x 计划仅需 10% 的利用率即可达到 API 等价盈亏平衡；Pro 和 5x 计划约 20%。OpenAI 由于定价策略更激进，Plus/Pro 5x 为 11.4%，Pro 20x 更是低至 5.7%。SemiAnalysis 团队认为，实际平均利用率（尤其对于 20x 计划）远高于这些阈值，意味着高等级订阅可能是负毛利产品。

实验室的应对策略

Anthropic 的企业版订阅计划完全不包含使用额度，所有用量按 API 价格另行计费。SemiAnalysis 自己虽然用着企业计划，实际上支付的是纯 API 价格。精明的初创公司则直接买多个个人订阅账号，额度用完再买一个——对于不在乎企业安全的年轻公司，这是最经济的选择。

Codex 每月 200 美元大概能获得 12,000 美元的 API 额度，Anthropic 是 8,000 美元。显然这是毫无疑问的选择。 Max Kan [08:30]
03

Anthropic 的利润机器

00:10:42 — 00:16:04
核心观点

凭借 80%+ 的 API 收入占比和超 85% 的毛利率，Anthropic 在 Q2 实现运营盈利，Q3 利润可能超 10 亿美元——这是其相对于 OpenAI 最核心的结构性优势。

深度阐述
盈利的秘密

Anthropic 目前 80% 以上的 ARR 来自 API 而非订阅计划。API 毛利率估计在 85% 以上，使得公司按非 GAAP 口径（剔除股权激励）实现盈利。Q3 利润可能超 10 亿美元，并非奇迹——而是收入增长极快，公司来不及招聘足够人员或把钱全部投入模型训练。

OpenAI 的结构性劣势

ChatGPT 拥有 9.5 亿周活跃用户，但仅约 6% 是付费用户（绝大多数每月 20 美元）。免费用户的大量推理成本拉低综合毛利率约 20 个百分点。不过这一差距正在缩小——OpenAI API 业务自 3 月以来快速增长，消费者/企业收入比已从 Q1 的 60/40 翻转到 Q2 的 40/60，净新增 ARR 与 Anthropic 持平。

用户付费转化差异

Claude 约 59% 的免费用户最终转化为付费用户——用户群更小但粘性更高。ChatGPT 大量用户仅将其用作「Google 搜索替代品」，付费意愿极低。广告业务是 OpenAI 探索的消费者端变现路径，但规模和难度都不可小觑。

Anthropic 第三季度利润可能超过 10 亿美元……部分原因在于他们增长太快，来不及招人或者把钱全部投入训练。 Joey Brookhart [11:00]

双雄对决：从 Anthropic 领先到 OpenAI 回归

00:16:04 — 00:20:41
核心观点

年初几乎被市场「判负」的 OpenAI 凭借 GPT-5.5/5.6 和 Codex 强势回归，Anthropic 在编程领域的绝对领先正在被蚕食，双雄格局重新确立。

深度阐述
OpenAI 的至暗时刻

2026 年头几个月 OpenAI 处境危险——ARR 增长在 3-4 月间出现停滞，大量企业和开发者转向 Claude Code。SemiAnalysis 在 GPT-5.5 发布时预测那将是转折点，事实证明预测的乐观程度甚至超出了预期。

5.6 vs Fable

GPT-5.6 被评价为与 Anthropic 的 Fable 同样出色，价格只有一半，且很可能是一个小得多的模型——从侧面证明了 OpenAI 的训练能力。Jordan（主持人）坦承：「我现在基本默认用 OpenAI了。」

从消费者到企业的渗透

OpenAI 在消费者端的 momentum 正在渗透到企业市场。以前 Claude Code 的超级用户不碰 Codex，现在开始说「不如试试」。这种趋势在 7 月中旬刚刚开始显现，预计将持续加速。

5.6 和 Fable 一样好，尽管价格只有一半……现在 OpenAI 和 Anthropic 的月净新增 ARR 已经旗鼓相当了。 Max Kan [17:38]

第三名之争：xAI 的回收条款革命

00:20:41 — 00:29:58
核心观点

AI 第三名之争远超第一名更激烈：xAI 的「算力回收条款」模式创新性地兼顾短期变现与长期冲刺 RSI；Meta 的 NeoCloud 为 MSL 提供后盾；Google 因算力无法回收被 Team 毫不留情排在第五。

深度阐述
回收条款的精妙设计

Elon Musk 将 Colossus 1 几乎全部租给 Anthropic，但每份合同包含 90 天回收条款——如果 xAI 证明自己可通过扩展算力达到 frontier 水平，即可随时收回全部算力。这使得 xAI 既能在短期内以 3-4 倍市场价变现算力，又不失长期冲刺 RSI（递归自我改进）的机会。团队认为这是一种极聪明的策略，但只有对真正相信自己能构建 RSI 的公司才有效。

Meta 的 NeoCloud 后盾

NeoCloud 为 Zuck 提供双重保险：如果 MSL 成功，算力自用；如果失败，可将算力以高于市场价的托管服务变现。据测算，Neocloud 在每吉瓦 120 亿美元收入时已是好生意，而 SpaceX/Google 的交易定价更高达市场价 4 倍（每吉瓦近 500 亿美元）。Anthropic 的每吉瓦收入在过去三个季度翻了一倍多，且可能继续加速。

Google 的第五名困境

Google 被排在第五名，原因有二：模型不够好（Gemini 3.5 Pro Flash 不行），更致命的是算力策略——签了大量不可回收的长期 TPU 合同，无法在需要时收回算力用于自身突破。团队将其解读为「缺乏打造 AGI 的信念」。DeepMind 高层连续离职也被视为此问题的直接后果。

Google 的问题在于……他们签了太多无法回收算力的长期 TPU 合同……这反映出他们缺乏对自己能构建 RSI 的信心。 Max Kan [24:57]

代币即服务市场的指数级增长

00:29:58 — 00:38:50
核心观点

代币即服务市场处于指数级增长初期，超大规模云厂商凭借企业渠道优势主导，推理创业公司虽份额永远有限但仍是好生意。

深度阐述
超大规模云的渠道霸权

AWS Bedrock、Azure Foundry、GCP Vertex AI 利用已有企业客户关系占据主导。Fortune 500 每年在云上花费九位数以上，AI 推理只是「在现有供应商基础上加一个选项」。六个月前代币即服务仅占 Anthropic 业务的 5%，现在已达约 20%。AWS 与 Anthropic 的交易中获得了 20-30% 的收入分成，几乎全部落到底线。

推理创业公司的策略困境

Together、Fireworks、Base 10 等公司虽增长迅速，但以全球代币量计算，当前可能是它们市场份额最高点的时刻。VC 的投资逻辑是「推理将成为史上最大市场，即使只拿极小份额也足够」。但一旦芯片公司达到规模，实验室会直接组建团队优化——不会长期依赖第三方平台。

新型芯片的变数

如果新型芯片创业公司找到明显优于 NVIDIA 的方案，推理平台可能成为核心分发渠道。但 Max 持怀疑态度：一旦达到足够规模，实验室会直接建立第一方优化能力。

Anthropic 每吉瓦收入在三个季度内翻了一倍多，有人认为未来两到三个季度还能再翻一倍。 Joey Brookhart [29:35]

RL 扩展定律：百亿美元的数据新产业

00:38:50 — 00:47:10
核心观点

强化学习（RL）是当前提升模型能力最重要的扩展定律，RL 数据市场正在催生百亿美元级的新产业——实验室几乎不计代价采购，单个高质量任务可报价五位数美元。

深度阐述
RL 扩展定律的革命性意义

预训练时代的「谁算力多谁赢」法则正在被改写。RL 让模型自主尝试完成白领工作任务，通过反复试错学会解决。许多人认为，阻止模型在电脑上做任何人类能做的事的唯一障碍，就是缺乏足够的高质量 RL 环境。2026 年头部实验室在此类数据上的预算将超 100 亿美元——约去年的 10 倍，2027 年完全可能再增长 10 倍。

Anthropic 编程领先的秘密

Anthropic 的模型曾是编程最好的（在 GPT-5.6/Soul 发布前），直接原因是它们最激进地购买了最多的 RL 编程数据。其他实验室正在意识到这一点并疯狂追赶。

构建 RL 任务：五位数美元的挑战

高质量编程任务的构建需要：优秀工程师花一天构思；创建验证器（集成测试+评分标准）；编写同时满足公正无歧义和自然真实两个矛盾要求的提示词。实验室为单个任务愿付五位数美元——最高质量任务的年收入可达七位数。

很多人认为，阻止模型在电脑上做任何人类能做的事情的唯一障碍，就是缺乏足够的 RL 环境。 Max Kan [39:26]
