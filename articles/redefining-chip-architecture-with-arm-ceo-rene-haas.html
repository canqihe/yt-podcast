Arm 从 IP 之王到亲自下场造芯 当 CPU 重新成为 AI 系统之心

全世界的目光都聚焦在 AI 加速器时，市值数千亿、毛利率曾高达 98.5% 的 Arm 宣布了一件"反常识"的事——作为芯片 IP 授权龙头，他们决定亲自下场造一颗 CPU：为 Meta 定制的通用智能体 CPU Arm AGI CPU。Arm CEO Rene Haas 与 No Priors 的 Sarah Guo、Elad Gil 深度对话，从供应链全知视角出发，讲透了四件事：Arm 为什么从"卖图纸"转向"卖芯片"；AI 如何在芯片行业内部掀起生产力革命；软银的资本与生态棋局如何为 Arm 铺路；以及在这场关于算力、制造与地缘的"无限游戏"中，为什么 CPU 依然是万物之心。

核心要点

01

从 IP 之王到亲自造芯

Arm 的主营业务是向全世界授权 CPU IP，毛利率曾高达 98.5%——没有库存、没有报废、没有退货授权。2024 年 3 月，Arm 推出第一款实体产品 Arm AGI CPU，客户是 Meta，因为"市面上没谁能给他们想要的通用智能体 CPU"。

02

客户没造反

CPU IP 的价值完全取决于生态。下场造芯前 Arm 几乎和所有客户谈过，反对声音比预想的小得多——英伟达、亚马逊、微软、谷歌全支持：外面可用的软件越多，对整个生态和客户自己越有利。

03

AI 是 Arm 工程师的"互联网"

芯片 24-36 个月周期的大头是验证、调试与文档，AI 恰好擅长。Arm 80%-90% 的工程师每天都在用 AI；关掉它，"就像回到 1990 年代只有凌晨两点到四点能上网"。RTL 生成与物理设计仍是短板，但正向模型厂商合作微调来弥合。

04

供应链紧约束 3-5 年

Rene 预测 5 年以上"想法直达 GDS2 流片文件"对简单设计可能成真；但只要 Transformer 还是 AI 的"能量单位"，计算密集与内存密集的天性不变，晶圆、内存、先进封装的紧约束至少还要持续 3-5 年。

05

软银 SB Neo 当"家"

软银刚宣布要做"新云" SB Neo：给有芯片技术的初创公司一个家，不必再低声下气去微软、谷歌那儿争设计中标。Arm 与软银共生，软银涉足的机器人、能源、数据中心都可能成为 Arm 产品的落点。

06

CPU 仍是万物之心

加速器是"token 工厂"，但总得有人把 token 运走交给人——那是 CPU 的活。在冯·诺依曼体系里 CPU、加速器、内存的结构从未改变；越往小形态走、越要把 AI 塞进边缘设备，Arm 的能效优势就越成为甜蜜点。

从 IP 授权到亲自造芯：Arm 在供应链中的双重身份

核心观点

Arm 在芯片供应链里有两个身份：既是向全世界授权 CPU 核心的 IP 巨头，又是从 2024 年 3 月才开始学着买基板、买晶圆、买内存的"实体芯片新玩家"。

深度阐述

Rene 用一句话点明了 Arm 的独特性："因为我们覆盖的市场太广，所以我们几乎什么都能看到。"全球绝大多数芯片——智能手机、数据中心、汽车——底层都跑着 Arm 授权的 CPU 核心；客户要么像三星一样自己造，要么把设计交给台积电流片。这让 Arm 能同时看到汽车、数据中心、智能手机的动向，对供应链拥有罕见的全方位视角。

真正让外界侧目的是战略转折：2024 年 3 月，Arm 发布了第一款实体产品 Arm AGI CPU，客户是 Meta。为什么一个靠"卖 IP、零库存、零报废"活了几十年的公司要下场？Rene 的解释是一个自然的演进链条：最初只卖 CPU IP、GPU IP、系统 IP 等零散部件；几年前发现产品周期没变慢、芯片制造时间却在拉长，"更快拿出方案"变得至关重要，于是推出"计算子系统"——用他的乐高比喻说，就是"我们提供蓝图，告诉你这些积木怎么拼"。子系统大受欢迎之后，实体产品是顺理成章的下一步：因为不是每个客户（比如 Meta）都有能力基于 Arm 造出自己想要的芯片，而市场上又没人能提供"通用智能体 CPU"这种新物种。

"There's no computing problem that's ever been invented that doesn't utilize and can't utilize the microprocessor. It is the heart of everything." — "从来不存在一个不利用、也无法利用微处理器的计算问题。它是万物之心。" 00:00:00
"Meta was that first example. They wanted a general purpose agentic CPU. There wasn't anybody out who could give it to them." — "Meta 就是第一个例子：他们想要一颗通用智能体 CPU，市面上没有谁能提供。" 00:04:06

token 工厂需要卡车：CPU 是万物之心

00:32:30 — 00:37:06
核心观点

ChatGPT 引爆后舆论一度"逢问题必答加速器"，但系统里总得有人做编排——"token 工厂"产出的海量 token 需要"卡车"运给用户，这份工作属于 CPU；越往边缘走，Arm 的能效优势越成为甜蜜点。
