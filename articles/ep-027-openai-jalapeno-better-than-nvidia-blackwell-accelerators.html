OpenAI Jalapeño 比英伟达 Blackwell 更强

2026 年 Hot Chips 大会最后一天，一个几乎所有人都预料到、却几乎没有人预料到性能的芯片亮相了——OpenAI 自研 ASIC「Jalapeño」。这颗由博通代工、以辣椒命名的芯片，在每兆瓦 Token 产出与每 TCO 性能上，直接击败了英伟达最新一代 Vera Rubin 与上一代 GB300。更令人震惊的不是它赢了，而是它怎么赢的：从概念到真实基准测试不到两年，流片仅 9 个月，期间大量借助 AI 完成芯片设计与内核编程。SemiAnalysis 的三位分析师 Bryan、Myron 和 Jordan 拆解了这颗芯片的性能曲线、微架构、编程模型，以及它对英伟达 CUDA 护城河的真正含义。

核心要点

01

指标陷阱

规格表上的算力/带宽是"保证你不会超过的上限"，不是可达到的数字；真实基准才是唯一可信的尺子。"每芯片性能"可通过胶水芯片轻松操纵，比"每兆瓦 Token"等场景化指标更易误导。

02

电力为王

数据中心正从算力受限转向电力受限，谁在"每兆瓦 Token 产出"上领先，谁就在推理经济的单位成本上领先——Jalapeño 对 GB300 是两倍。

03

CUDA 神话动摇

Jalapeño 是第一个在真实 Pareto 曲线上每一点都击败英伟达的芯片（快与便宜兼得），但"英伟达模式"（供应链、生态、运维）仍是更大的护城河。

04

AI 造芯成真

用 GPT-5 之前的模型即可在 RTL 阶段省下 8%-10% 面积；3 万行 AI 生成汇编内核无人能读懂却性能出色——"先拥有最强模型"的优势正转化为硬件优势。

05

隐藏的实力

OpenAI 用单 Token 预测参战（弃用 MTP），还藏着 3-5 倍提升的内部投机解码；Jalapeño 的真实实力被显著低估。

06

三星逆袭

HBM4 世代三星凭 1c 工艺 + 4 纳米逻辑基底反超海力士，700 瓦 TDP 实现 15.4 TB/s 带宽（每瓦带宽为 Rubin 两倍）——硬件供应链的胜负手往往在芯片之外。

深度洞察

01

Jalapeño 亮相：性能全面碾压，但对比需要"对齐"

01:05 - 04:22
核心观点

OpenAI 自研 ASIC Jalapeño 在每兆瓦与每 TCO 性能上击败 Vera Rubin 的 7 月测试结果，对 GB300 更是完全碾压；但跨代对比 HBM3 与 HBM4 并不公平，且双方软件成熟度需要对齐。

深度阐述

Hot Chips 大会最后一天的这场演讲，被 SemiAnalysis 称为"最令人意外的演讲之一"。所有人都知道 OpenAI 的芯片项目在推进、并已宣布与博通（Broadcom）合作，但性能数据首次公布时，依然让全场吃惊。主持人特意强调了一个公平性前提：他们对比的是 Vera Rubin 的 7 月测试结果，而非最新状态——因为在那个时间点，双方软件的优化程度是相似的，这样对比才成立。

与 GB300 相比，Jalapeño 在几乎所有维度上都"完全碾压"，但 Myron 指出这并不公平：GB300 用的是 HBM3，而 Jalapeño 用的是 HBM4，跨代内存对比会让结果失真，因此分析师选择以 Rubin 为参照系。Jordan 补充了一个关键细节：这些基准跑的是 DeepSeek R1（8K 输入、1K 输出），既不是绝对最大的模型，也不是最严苛的推理负载——仅仅是随机数据，而非智能体（Agent）工作流。

以周为单位的迭代速度

另一个值得注意的现象是迭代速度：Jalapeño 的性能以周为单位、甚至以天为单位在提升。从首次公布到现在短短 25 天，性能曲线已经显著上移，这种快速迭代能力本身就是信号——它意味着软件栈已经相当成熟，芯片的潜力远未释放完。

"Jalapeño 在每兆瓦性能和每 TCO 性能上，实际上击败了 Vera Rubin 的 7 月测试结果……对 GB300 来说，它完全碾压了对方。" [02:29]
02

每兆瓦 Token：电力才是数据中心真正的约束

04:22 - 09:15
核心观点

当数据中心受电力而非算力限制时，"每兆瓦 Token 产出"成为比"每芯片 Token 吞吐"更有意义的指标；OpenAI 自用芯片，因此只关心前者。

深度阐述

黄仁勋在 2026 年 Computex 主题演讲中提出了一个判断：数据中心正在变得电力受限，电力正成为瓶颈。你有钱就能买到更多服务器和芯片，但一座数据中心的电力容量是物理上限——100 兆瓦就是 100 兆瓦，只能装下那么多芯片。各公司尝试过表后计量（BTM，behind-the-meter）电力等办法，但归根结底，电力才是约束。

"每芯片性能"是可以被操纵的指标

行业最常见的比较方式是每 GPU（每个封装）的 Token 吞吐量，但 SemiAnalysis 指出，"每芯片性能"本质上是一个可以被操纵的指标——把两颗芯片粘在一起，每芯片性能就翻倍了，Vera Rubin Ultra 和 Blackwell Ultra 正是这么做的；Cerebras 甚至可以把三片晶圆放进一个机架，然后声称"三比一好"。因此，对不同的玩家应该用不同的尺子。

自研芯片的核心理由

OpenAI 的独特之处在于：Jalapeño 没有外部客户，只为自用，所以他们不关心每封装 Token，只关心"每兆瓦进入系统的 Token"。SemiAnalysis 做了 TCO 测算，假设 OpenAI 自购自营（而非按当前 NeoCloud 每小时 6 美元的市价），成本假设为：GB300 每小时 279 美元、Vera Rubin 每小时 361 美元、Jalapeño 每小时 156 美元——这正体现了自研芯片的核心理由：只付博通的代工利润，而不是英伟达的整机利润。即便按每 TCO 性能计算，Jalapeño 也依然胜出或非常接近。

"如果你有 100 兆瓦的电力，你只能装下那么多芯片。如果这些芯片每兆瓦更贵，其实并不重要——只要它们每兆瓦产出更多 Token。" [05:07]
03

基准测试的注意事项：一只手背在身后作战

09:15 - 13:48
核心观点

Jalapeño 用单 Token 预测（STP）击败了使用多 Token 预测（MTP）的 Vera Rubin；OpenAI 还隐藏了内部投机解码技术（3-5 倍提升），实际实力被严重低估。

深度阐述

基准测试覆盖了三个模型：基于 V3 架构的 DeepSeek V3.1（6000 亿总参数）、Kimi K2.5（约 1 万亿参数）、以及 OpenAI 自家开源模型 GPT-OSS 12B（相对较小）。三个模型上，Jalapeño 都击败了 Vera Rubin——而且是在一个关键不利条件下做到的。

单 Token 预测 vs 多 Token 预测

MTP（Multi-Token Prediction，多 Token 预测）是一种投机解码形式：模型在一次前向传播中同时猜测并验证多个未来 Token（因为语言模型实际上会输出每个 Token 位置的概率分布）。英伟达的 Rubin 使用 MTP，而 OpenAI 提交的 Jalapeño 结果用的是单 Token 预测（STP），这相当于"一只手背在身后战斗"——MTP 对交互延迟是巨大的优化。

被隐藏的内部投机解码

Jordan 进一步披露了一个令人玩味的细节：有传言称 OpenAI 和 Anthropic 内部很可能有类似 MLA（Multi-head Latent Attention，多头潜在注意力）的实现，但 OpenAI 明确表示没有任何内部 MLA 内核——这意味着 OpenAI 没有任何模型使用 MLA 这种 DeepSeek 的标志性架构。此外，OpenAI 没有提供投机解码的基准结果，Jordan 的个人猜测是：他们有一套既非 MTP、也非开源方案的内部投机解码技术，因为无法通过开源实现验证，所以干脆不公开。而据团队透露，这套内部技术在生产模型上能带来 3 到 5 倍的性能提升——如果属实，Jalapeño 对 Vera Rubin 的对比将再次被拉大数倍。

SemiAnalysis 还提到，他们曾邀请 OpenAI 团队在自家 Agent X 基准上运行测试（能衡量前缀缓存等更多优化空间），但时机不佳未能成行。

"我们被告知，他们内部的投机解码方法在量产模型上能带来 3 到 5 倍的提升。这会让 Jalapeño 对 Vera Rubin 的对比再次被碾压。" [13:26]
04

CUDA 护城河：第一颗真正构成威胁的芯片

13:48 - 21:12
核心观点

Jalapeño 是首个在真实基准的 Pareto 曲线上每一点都击败英伟达的非英伟达芯片——既快又便宜，这是此前所有挑战者都没做到的。

深度阐述

面对"它只是个 ASIC，没什么稀奇"的论调，SemiAnalysis 的回应是：如果软件足够好，能让一颗芯片快速跑起来，那么"ASIC 与 GPGPU"这条界线就不再重要。关键在于证据——此前从未有任何公司拿出一张图，显示自己在真实测试曲线上每一点都击败英伟达。

Pareto 曲线：两端都赢

分析师用 Pareto（帕累托）曲线解释性能声明：Y 轴是每兆瓦电力产出的 Token 数（决定成本效率），X 轴是每个用户看到的 Token 速度（决定交互体验）。结论是 Jalapeño 在曲线两端都赢了：固定交互性（如每用户每秒 50-100 Token）下，Jalapeño 每兆瓦产出的 Token 数是 GB300 的两倍——意味着推理服务商的收入与利润直接翻倍；在极低批处理、最高交互场景下，Jalapeño 可达每用户每秒 700 Token，而其他竞品峰值仅 350，又是两倍。

挑战者们的分水岭

这正是过去挑战者们的分水岭：Groq、Cerebras、D-Matrix、SambaNova 等押注 SRAM 与快速解码的玩家只追求"快 Token"，放弃吞吐量；AMD、TPU、Trainium 等追求吞吐量的玩家则承认在高交互性上无法竞争。OpenAI 是第一个两者兼得的。Jordan 还点出了一个里程碑意义：Jalapeño 是第一个登上 SemiAnalysis 公开 Inferentia X 基准的非英伟达、非 AMD 芯片——此前他们本以为会是 SambaNova 或 Cerebras。他们曾公开邀请 Etched 来跑基准，但对方没有回应。至于黄仁勋本人的回应，在 Mad Money 节目上他的态度是"我不担心"。

真正的护城河

Bryan 提醒，真正的护城河不止是 CUDA 软件生态，而是"英伟达模式"：包括供应链、购买渠道、部署物流、监控运维在内的整个体系。OpenAI 接下来要面对的是如何点亮 100 兆瓦的这类芯片，而不仅是三台测试机架——从概念到实验室真实芯片不到两年、流片不到 9 个月，这个速度本身就令人咋舌。

"我们从未见过任何其他人拿出一张图，显示他们在曲线上每一点都击败了英伟达，而且是在真实测试中。" [14:36]
05

OpenAI 是怎么做到的：AI 辅助设计 + TPU 班底

21:12 - 32:13
核心观点

Jalapeño 的规格在纸面上并不亮眼（FP4 算力不到 Rubin 一半、TDP 约三分之一），却能大幅超越对手——关键在于减少数据搬运的微架构哲学与 AI 辅助的软硬件协同。

深度阐述

Myron 提出了一个极具讽刺意味的观察：正是英伟达的硬件，让摆脱英伟达的硬件成为可能。OpenAI 用英伟达 GPU 训练出足够强的模型，让 AI 能够编写内核、辅助芯片设计，从而降低了采用替代性硬件栈的门槛。Anthropic 引入 AMD 作为硬件供应商，也是因为 Triton 编程能绕开 AMD 软件栈的挑战。

几乎全是前 TPU 成员的团队

团队背景方面，OpenAI 硬件团队中有大量前 TPU 成员——Jordan 指出一个行业现象：几乎所有 AI 加速器初创公司都出自谷歌 TPU 团队，几乎没有前英伟达团队，这本身就很值得玩味。有了这样的班底，第一代产品"不错"是预期，但"比英伟达最好的产品还好"就远超预期了。这同时让 Meta（MTIA）和微软（Maia）的芯片团队显得尴尬——他们同样投入多年，却没有产出同等成果。

反直觉的规格对比

规格对比是这篇文章最反直觉的部分：Jalapeño 是 HBM4 芯片，拥有出色的 HBM 带宽，但 FP4 算力不到 Rubin 的一半，HBM 容量更少，单芯片 TDP 约 700 瓦（Rubin 可达 1800 瓦，约为其三倍）。过去 AMD 的看多者论证 MI450 的方式就是列规格：更高算力、更大容量、更高带宽、更高 TDP，所以更好——但他们从不愿意看真实基准结果。Jalapeño 证明了：规格表上的数字不是"你能达到的数字"，而是"制造商保证你永远不会超过的数字"（Jordan 引用了一句出处不明的名言）。大多数工作负载根本碰不到 Roofline 模型（屋顶线模型）的上限，因此算力数字在很大程度上是营销产物。

核心设计哲学：减少数据搬运

SemiAnalysis 总结出的核心设计哲学是：任何人都能买到最好的 HBM 然后堆更多层，真正难的是在微架构中减少数据搬运，让芯片实际兑现 HBM 带宽。很多芯片卡在复杂的内存子系统和大量数据搬运上，无法接近理论带宽。Jalapeño 正是靠"降低数据搬运的微架构"兑现了海量 HBM 带宽——这才是真正的护城河。

"这些数字不是你能达到的数字，而是制造商能保证你永远不会超过的数字。" [30:37]
06

三星 HBM4：带宽/瓦特之王

32:13 - 42:10
核心观点

三星凭借 1c DRAM 工艺与 SF4 4 纳米逻辑基底，在 HBM4 上反超海力士；Jalapeño 以 700 瓦 TDP 实现 15.4 TB/s 带宽，每瓦带宽是 Rubin 的两倍，这是其每瓦 Token 优势的物理来源。

深度阐述

历史充满了反转。SK 海力士与 AMD 联合发明了 HBM（最初是为游戏 GPU 设计的，后来才被 AI 这个"内存带宽极度饥渴"的应用捡走），并长期主导市场；三星在 HBM3/HBM3E 时代则因工艺劣势表现糟糕。但到了 HBM4，局势逆转：三星的 DRAM 芯片采用更先进的 1c 工艺，HBM 立方体中的逻辑基底芯片（集成 PHY 物理层接口）采用 SF4（三星代工 4 纳米节点）先进逻辑工艺；海力士的基底芯片用台积电 12 纳米，DRAM 仍用与 HBM3E 相同的 1b 工艺；美光的基底芯片仍用自家 DRAM 工艺，导致在 HBM4 最高速度上遇到困难，需要重新设计基底，也因此推迟了向英伟达 Rubin 的 HBM4 交付。

Jalapeño 正是这一技术红利的受益者：实现 15.4 TB/s 的 HBM4 带宽（每引脚 10 Gbps），高于外界预期英伟达 Rubin 将采用的 9.6 Gbps。这究竟是运气还是决策？Myron 指出，博通的 HBM 传统上主要来自三星，这算是一种"运气"，但在 HBM4 时代变成了优势。

堆叠层数的反直觉讨论

关于堆叠层数的讨论同样反直觉：8 层、12 层还是 4 层高，带宽其实相同，付钱买的是容量。随着 HBM 晶圆供应紧张、价格上升，越来越多公司开始选择更低的堆叠层数（6-high、4-high）以优化"每美元带宽"——尤其是在超大规模（rack-scale）架构下，容量已不再是主要瓶颈。

震撼的带宽/瓦特数据

但最震撼的数据是带宽/瓦特：以 700 瓦 TDP 实现 15.4 TB/s，换算后该比率（任意单位 22）是 Rubin 的整整两倍。即使把 Rubin 降到 1800 瓦低功耗模式，其带宽也只多约 25%（20 vs 15 TB/s），功耗却是两倍多。这个"带宽每瓦"优势，正是每瓦 Token 产出优势的直接来源。至于下一代 B0 步进（目前结果均出自 A0 步进），Jordan 认为 HBM 带宽已接近内存本身的物理极限，但 B0 应在相同功耗下提供更高算力。

"他们在 700 瓦 TDP 的芯片上实现了每秒 15.4 TB 的带宽……这个带宽-功率比是 Rubin 的两倍。你的每瓦 Token 产出优势就来自这里。" [39:08]
07

AI 设计的芯片：从 RTL 到内核的全栈 AI

42:10 - 49:24
核心观点

AI 在两个阶段深度参与：设计阶段（RTL 冻结前，用 GPT-5 之前的模型将 SIMD 面积减 8%、矩阵引擎面积减 10%）与启动阶段（用强化学习循环迭代优化内核）；OpenAI 把"比对手更早用上最强模型"的优势留给了自己。

深度阐述

Jordan 将 AI 参与分为"设计"与"启动（bring-up）"两个阶段，并纠正了一个常见误解：设计阶段的 AI 辅助发生在 GPT-5 之前。Jalapeño 的 RTL（寄存器传输级设计）冻结于去年 7 月，从 2 月到 7 月间，AI 辅助帮助团队将 SIMD 面积缩减 8%、矩阵引擎面积缩减 10%。这本身就是一个惊人的声明——很多人能理解 AI 写内核或软件工程（放入 codex 式循环、自动测试迭代），但很少有人意识到更旧的模型已经足以加速流片前最繁琐的人工 RTL 工作。

启动阶段与强化学习的契合

启动阶段则完美契合强化学习的优势：内核优化是迭代的、可验证的领域——交给模型一个任务（提高内核性能、通过验证脚本），让模型放手去试，构建 RL 环境、投入足够的 Token、推理时间与 rollout（采样尝试），就能得到好结果。

从 AI 中获益最大的不是 AI 公司

由此引出一个更宏观的判断：从 AI 中获得最大价值的，从来不是提供 AI 的公司本身。OpenAI 和 Anthropic 长期不盈利，而 Jane Street 一个季度靠 AI 交易赚 150 亿美元。Jalapeño 是一个绝佳的例证——OpenAI 把"先于所有人用上最强模型"的能力留给了自己：他们能流片出这颗芯片，而竞争对手不能。这就是未来趋势的缩影：前沿模型公司将进入所有"与软件间接相关、模型需要控制计算机"的领域。Anthropic 也在做同样的事——开始招聘芯片人才，并让语言模型控制显微镜、深入生物科学。

"OpenAI 把比其他人更早拥有模型的优势留给了自己，这是一个非常明显的例子。他们可以流片出一颗芯片，而他们的竞争对手不能。" [46:06]
08

架构深度解析：小脉动阵列 + 硬件缓存 + AI 生成的汇编

49:24 - 56:58
核心观点

Jalapeño 采用"TPU 式但更小的脉动阵列"设计，规避了大脉动阵列在瘦矩阵上的效率悬崖；用硬件 L1 缓存而非软件管理暂存器；内核是 AI 生成的 Gluon 汇编——人类工程师一行也看不懂，但它就是跑得又快又对。

深度阐述

先说一个"愤世嫉俗"的视角：对 OpenAI、Anthropic、Meta、微软而言，自研芯片项目可能是一种"假动作"——花几亿美元、一两年时间流片，就可能在数千亿美元规模的 GPU 采购谈判中获得折扣，项目轻松回本。但非愤世嫉俗的视角是：这是真东西，未来只会更深入，RTL 到流片的时间也只会比 9 个月更短。

小脉动阵列：规避效率悬崖

架构上，Jalapeño 的高层形态是"小脉动阵列的 TPU"。脉动阵列（systolic array）是 TPU 处理单元的经典排布方式，但 TPU、Trainium、Etched、MatX 等采用大脉动阵列的芯片有一个通病：瘦矩阵（skinny GEMM）效率悬崖——当 M 维度很小（如低并发、多专家场景），或维度略超 128/256 的边界时，会为跑一个瘦矩阵乘法而发起整个内核启动，大量处理单元闲置，算力无法最大化。解决方案就是用更小的脉动阵列配合高效分块（tiling），减少填充与对齐开销——代价是需要更多小单元，可能损失部分能效。OpenAI 的解法是：智能放置权重与内核（KB），选择性进行核间同步，极其节约地使用连接 HBM 切片与计算单元的收集网络（collective network，即片上网络 NoC）。

反其道而行的 L1 缓存

结果是一颗"比 GPU 更容易推理、比 TPU 更灵活"的芯片：GPU 编程经验（OpenAI 极擅长）与 TPU 设计经验（团队背景）的结合产物。一个有趣的细节是它拥有 L1 缓存——几乎所有现代加速器都放弃了 L1，只靠 L2/SRAM 软件管理暂存器（scratchpad）。OpenAI 反其道而行，用硬件缓存降低编程难度，代价是需要靠 CPU 端的工作来掩盖数据搬运延迟。

3 万行 AI 生成的汇编

最后的震撼来自软件侧：与 OpenAI 工程师实地考察时，SemiAnalysis 团队浏览了一个 3 万行的内核文件——完全是 AI 生成的汇编代码，用 Gluon（基于 Triton 构建的低级内核编程语言）"吐"出来的。工程师们懂硬件、懂系统概念，但对那个 DeepSeek MLA 内核的实际工作原理一无所知，逐行看过去全是"不知道、不知道"。但这并不重要：AI 理解它，AI 测试它，它产出正确且性能出色的内核。这再次印证了趋势——当 AI 懂得操纵硬件上的数据搬运与处理单元时，人类是否逐行理解代码已不再重要。

"这个 3 万行的文件，完全是 AI 生成的汇编……工程师们逐行看过去：不知道、不知道、不知道。但这并不重要，AI 理解它，它测试它，它产出正确且性能出色的内核。" [55:40]
09

通用推理芯片与行业展望

56:58 - 63:06
核心观点

Jalapeño 是通用推理芯片而非模型协同设计产物（证据：能以 36 FPS 跑《毁灭战士》）；它对 Anthropic 的芯片项目设定了极高基准；人类语言的能量效率目前仍是机器的 20 倍以上。

深度阐述

收尾部分抛出三个未展开的话题：其一，Jalapeño 不做预填充/解码分离（PD 分离）——Bryan 表示这正是他最想吐槽的（他常年调试 PD 分离），意味着这仍是可大幅优化的空间；其二，系统的扩展（scale-up/scale-out）架构复杂到"播客上讲不清楚，请读原文"；其三，它是一颗通用推理芯片，并未与 OpenAI 自家模型协同设计——最有力的证据是它能以每秒 36 帧运行《毁灭战士》（Doom）。OpenAI 团队在展示这颗"开创性芯片"时，被问"它能跑 Agent X 吗？"——答案是"不能"（Agent X 测试得分 96%）。

Anthropic 的九个月之约

展望层面，Anthropic 已开始组建芯片团队。按 OpenAI 的时间线推算（约一个半月到 RTL 冻结、再四五个月流片），一个 9 个月周期后，Anthropic 定制芯片的 Token 就可能问世——主持人用"一次孕期"的比喻调侃了这一节奏。Bryan 认为，Jalapeño 为 Anthropic 设定了一个极高的基准，但 Anthropic 完全有理由达成类似结果。

卡路里对比与杰文斯悖论

最后的彩蛋是"卡路里对比"：把推理效率换算成人类语言能量效率，人类语言（每秒 3.3 Token）的能量效率约为并发 GB300 配置（每秒 180 Token）的 20-22 倍。Caveat 是："不是所有人类说出的 Token 都是高质量的。" 主持人以杰文斯悖论（效率提升反而刺激更多需求）收尾：希望每个生产芯片的公司都因效率提升而消费更多 Token、生产更多芯片、雇佣更多人。

"它是一颗通用推理芯片，并没有与他们的模型协同设计——证据就是它能以每秒 36 帧运行《毁灭战士》。" [57:02]

精华收获

📏

指标陷阱

规格表上的算力/带宽是"保证你不会超过的上限"，不是可达到的数字；"每芯片性能"可被胶水芯片操纵，比"每兆瓦 Token"等场景化指标更易误导。真实基准才是唯一可信的尺子。

⚡

电力为王

数据中心正从算力受限转向电力受限，谁在"每兆瓦 Token 产出"上领先，谁就在推理经济的单位成本上领先——Jalapeño 对 GB300 是两倍，推理服务商的利润直接翻倍。

🧱

CUDA 神话动摇

Jalapeño 是第一个在真实 Pareto 曲线上每一点都击败英伟达的芯片（快与便宜兼得），但"英伟达模式"——供应链、购买渠道、部署物流、监控运维——仍是更大的护城河。

🤖

AI 造芯成真

用 GPT-5 之前的模型即可在 RTL 阶段省下 8%-10% 面积；3 万行 AI 生成汇编内核无人能读懂却性能出色——"先拥有最强模型"的优势，正变成"先流片出最强芯片"的硬件优势。

🎭

隐藏的实力

OpenAI 用单 Token 预测参战（弃用 MTP 这一巨大延迟优化），还藏着 3-5 倍提升的内部投机解码——Jalapeño 的真实实力被显著低估，性能潜力远未释放完。

🏭

三星逆袭

HBM4 世代三星凭 1c 工艺 + 4 纳米逻辑基底反超海力士，700 瓦 TDP 实现 15.4 TB/s 带宽（每瓦带宽为 Rubin 两倍）——硬件供应链的胜负手往往在芯片之外。

OpenAI Jalapeño：AI 芯片的新纪元

这场对话的核心洞见是：规格表上的数字是"保证你不会超过的上限"，真实基准才是唯一可信的尺子；数据中心从算力受限转向电力受限，"每兆瓦 Token"成为新的胜负手；AI 已经能设计芯片、编写无人能懂的内核汇编——"先拥有最强模型"的优势正在变成硬件优势。Jalapeño 或许不是英伟达的终结，但它第一次证明：CUDA 护城河并非不可逾越。
